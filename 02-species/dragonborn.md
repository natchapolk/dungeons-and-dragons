# คนมังกร (Dragonborn)

[กลับหน้ารวม Species](00-species-overview.md) | [สารบัญ](../README.md)

---

## ภาพรวม

**คนมังกร (Dragonborn)** คือเผ่าพันธุ์ที่มีสายเลือดมังกร มีเกล็ดปกคลุมร่างกาย ยืนสองขาแบบมนุษย์ แต่มีหัวและหางแบบมังกร พวกเขาสืบทอด **ลมหายใจธาตุ** และ **ความต้านทานธาตุ** จากบรรพบุรุษมังกร

> **เหมาะกับ:** ผู้เล่นที่อยากเล่นตัวละครดูเท่ มีความสามารถโจมตีเป็นพื้นที่ตั้งแต่เลเวล 1 และอยากบินได้ในเลเวลกลาง

## Draconic Ancestry — สายเลือดมังกร (เลือกก่อน)

ก่อนอื่นต้องเลือกว่าคุณสืบเชื้อสายจากมังกรชนิดไหน **การเลือกนี้กำหนดธาตุของคุณตลอดทั้งเกม**

| Dragon (มังกร) | Damage Type (ธาตุ) |
|---|---|
| **มังกรดำ (Black)** | **กรด (Acid)** |
| **มังกรน้ำเงิน (Blue)** | **สายฟ้า (Lightning)** |
| **มังกรทองเหลือง (Brass)** | **ไฟ (Fire)** |
| **มังกรบรอนซ์ (Bronze)** | **สายฟ้า (Lightning)** |
| **มังกรทองแดง (Copper)** | **กรด (Acid)** |
| **มังกรทองคำ (Gold)** | **ไฟ (Fire)** |
| **มังกรเขียว (Green)** | **พิษ (Poison)** |
| **มังกรแดง (Red)** | **ไฟ (Fire)** |
| **มังกรเงิน (Silver)** | **เย็น (Cold)** |
| **มังกรขาว (White)** | **เย็น (Cold)** |

> **แนะนำ:** **Lightning** และ **Fire** เป็นธาตุที่ศัตรูต้านทานน้อยกว่า **มอนสเตอร์จำนวนมากมี Immunity ต่อ Poison (Poison)**
> **Poison เป็นธาตุที่ศัตรูต้านทานเยอะที่สุดในเกม** — หลีกเลี่ยง Green Dragon ถ้าเน้นประสิทธิภาพ

## ความสามารถพิเศษ (Traits)

### 1. Breath Weapon — ลมหายใจธาตุ

> **แทนที่การโจมตี 1 ครั้ง** เมื่อใช้ Attack action **คุณสามารถพ่นลมหายใจธาตุแทนได้**

| หัวข้อ | รายละเอียด |
|---|---|
| **รูปทรง** | เลือกระหว่าง **Cone 15 ฟุต** หรือ **Line 30 ฟุต × กว้าง 5 ฟุต** |
| **Saving Throw** | เป้าหมายทอย **DEX Save** — DC = **8 + CON modifier + Proficiency Bonus** |
| **ดาเมจ** | **1d10** ธาตุตาม Draconic Ancestry (ล้มเหลว = เต็ม, สำเร็จ = ครึ่ง) |
| **จำนวนครั้ง** | **เท่ากับ Proficiency Bonus ต่อ Long Rest** (เลเวล 1-4 = 2 ครั้ง) |

**ดาเมจเพิ่มขึ้นตามเลเวล:**

| เลเวลตัวละคร | ดาเมจ |
|---|---|
| 1-4 | **1d10** |
| **5-10** | **2d10** |
| **11-16** | **3d10** |
| **17-20** | **4d10** |

> **จุดที่ทำให้แรง:** ใช้แทนการโจมตี 1 ครั้ง ดังนั้นถ้าคุณมี **เลเวล 5+ (Extra Attack)** คุณสามารถ **พ่นลมหายใจ + โจมตีด้วยอาวุธ ในเทิร์นเดียวกัน** ได้

---

### 2. Damage Resistance — ความต้านทานธาตุ

> **คุณมี Resistance ต่อ Damage Type ตาม Draconic Ancestry ของคุณ**

**ทำไมดี:** รับดาเมจธาตุนั้น **ครึ่งเดียว** ตลอดเวลา ไม่ต้องใช้อะไรเลย — ทรงพลังมากในการสู้กับมอนสเตอร์ที่ใช้ธาตุนั้น

---

### 3. Darkvision — การมองเห็นในความมืด

> **มองเห็นในความมืดได้ไกล 60 ฟุต** (มืดสนิท เห็นเป็น Dim Light, Dim Light เห็นเป็น Bright Light)

 มองเห็นเป็นสีเทาขาว ไม่เห็นสี

---

### 4. Draconic Flight — ปีกมังกร (เลเวล 5)

> **เมื่อคุณถึงเลเวล 5** คุณสามารถใช้ **Bonus Action** เพื่อสร้างปีกวิญญาณชั่วคราว
>
> - ได้ **Fly Speed เท่ากับ Speed ปกติ** (30 ฟุต)
> - **คงอยู่ 10 นาที** หรือจนกว่าคุณจะ Incapacitated / ตาย / ใช้ Bonus Action ยกเลิก
> - **ใช้ได้ 1 ครั้งต่อ Long Rest**
> - ต้องไม่ใส่ **Medium หรือ Heavy Armor** ขณะบิน

**ทำไมดี:** การบินได้ในการต่อสู้ทรงพลังมาก — หนีจากศัตรูที่ตีระยะประชิดได้ทั้งหมด และเข้าถึงจุดที่คนอื่นไปไม่ได้

## คลาสที่เข้ากันดี

| Class | เหตุผล |
|---|---|
| **Paladin** [แนะนำ] | Breath Weapon ใช้ CON Save DC และ Paladin มี CON สูง + แทนการโจมตีได้ดี |
| **Fighter** [แนะนำ] | Extra Attack เยอะ = พ่นลมหายใจ + ตีได้หลายครั้ง |
| **Barbarian** | CON สูงมาก ทำให้ Breath Weapon DC สูง |
| **Sorcerer** (Draconic) | เข้าธีมสายเลือดมังกรอย่างสมบูรณ์แบบ |
| **Warlock** | บินได้ + ธีมพลังเหนือธรรมชาติ |

> **จุดสำคัญ:** Breath Weapon DC ใช้ **CON modifier** ไม่ใช่ค่าร่ายเวท — ดังนั้นคลาสที่มี CON สูงจะใช้ได้ดีที่สุด

## การเล่นบทบาท

Dragonborn มักถูกเลี้ยงมาในวัฒนธรรมที่ให้ความสำคัญกับ **เกียรติยศ ความภักดี และการพิสูจน์ตัวเอง** ต่อกลุ่ม/ตระกูล

### แนวคิดตัวละคร
- **นักรบผู้ไร้ตระกูล** — ถูกขับไล่จากเผ่า ออกเดินทางเพื่อกอบกู้ชื่อเสียง
- **ผู้แสวงหามังกร** — ตามหาบรรพบุรุษมังกรที่แท้จริงของตน
- **ทหารรับจ้าง** — ใช้พละกำลังและลมหายใจธาตุหาเลี้ยงชีพ

### คำถามช่วยสร้างบุคลิก
- คุณภูมิใจหรืออับอายในสายเลือดมังกรของตัวเอง?
- ตระกูล (Clan) ของคุณยังยอมรับคุณอยู่ไหม?
- คนอื่นกลัวคุณหรือเคารพคุณเวลาเห็นคุณครั้งแรก?

## สรุป Dragonborn ในหนึ่งบรรทัด

> **มีการโจมตีเป็นพื้นที่ตั้งแต่เลเวล 1 + ต้านทานธาตุถาวร + บินได้ตอนเลเวล 5 = เผ่าที่เท่และใช้งานได้จริงในทุกเลเวล**
