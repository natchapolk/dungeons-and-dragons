| Condition | ผลย่อ |

## รายละเอียดแต่ละสภาวะ

### ตาบอด (Blinded)
- มองไม่เห็นอะไรเลย และ **ล้มเหลวอัตโนมัติ** ในทุก Ability Check ที่ต้องใช้การมองเห็น
- **Attack Roll ของเราเสียเปรียบ (Disadvantage)**
- **Attack Roll ที่ศัตรูตีเราได้เปรียบ (Advantage)**

### ถูกเสน่ห์ (Charmed)
- **ทำร้ายผู้ที่ทำเสน่ห์เราไม่ได้** ไม่ว่าจะด้วยการโจมตีหรือสเปลที่เป็นอันตราย
- ผู้ทำเสน่ห์ทอย **Ability Check ทางสังคม (Charisma) ใส่เราแบบได้เปรียบ**
- ยัง**ขยับได้และทำอย่างอื่นได้ปกติ** — ไม่ใช่การควบคุมร่างกาย

### หูหนวก (Deafened)
- ไม่ได้ยินอะไร และ **ล้มเหลวอัตโนมัติ** ใน Check ที่ต้องใช้การได้ยิน
- **ยังร่ายเวทที่มีองค์ประกอบ Verbal ได้** (ตัวเองพูดได้อยู่)

### หวาดกลัว (Frightened)
- **ทอย Ability Check และ Attack Roll เสียเปรียบ** ตราบที่ยัง**มองเห็น**ต้นเหตุของความกลัว
- **เคลื่อนที่เข้าใกล้ต้นเหตุไม่ได้** (แต่ถอยห่างได้)
- **เคล็ดลับ:** ถ้าหลบไปหลังกำแพงจนมองไม่เห็นต้นเหตุ ก็จะไม่เสียเปรียบ

### ถูกจับล็อก (Grappled)
- **Speed = 0** และไม่ได้รับโบนัสความเร็วใด ๆ
- **Attack Roll เสียเปรียบ** ยกเว้นตีคนที่จับเราอยู่
- **ขยับตามได้** ถ้าคนจับเดิน (คนจับใช้ระยะ 2 เท่า)

**วิธีหลุด:** ใช้ **Action** ทอย **Athletics (STR)** หรือ **Acrobatics (DEX)** เทียบกับ **DC ของคนจับ (8 + STR mod + Prof)**
สภาวะจบทันทีถ้า: คนจับ Incapacitated, ระยะห่างเกินระยะเอื้อม, หรือคนจับปล่อยเอง

### ไร้ความสามารถ (Incapacitated)
สภาวะพื้นฐานที่ซ่อนอยู่ในหลายสภาวะอื่น:
- **ทำ Action, Bonus Action, Reaction ไม่ได้**
- **ร่ายเวทไม่ได้**
- **Concentration ขาดทันที**
- **ทอย Initiative เสียเปรียบ**
- **พูดไม่ได้**

### ล่องหน (Invisible)
- ศัตรูมองไม่เห็นเรา (เว้นแต่มีความสามารถพิเศษ เช่น Truesight)
- **เราซ่อนตัวได้** (Hide)
- **Attack Roll ของเราได้เปรียบ**
- **Attack Roll ที่ศัตรูตีเราเสียเปรียบ**
- กฎ 2024: การใช้ **Hide action สำเร็จ ให้สภาวะ Invisible** กับเรา (จบเมื่อเราโจมตี/ร่ายเวท/ส่งเสียง หรือศัตรูหาเจอ)

### เป็นอัมพาต (Paralyzed)
- **Incapacitated** + ขยับไม่ได้ + พูดไม่ได้
- **ล้มเหลวอัตโนมัติใน STR Save และ DEX Save**
- **ศัตรูตีเราได้เปรียบ**
- **ศัตรูที่ตีเราในระยะ 5 ฟุต = Critical Hit ทุกครั้ง**

### กลายเป็นหิน (Petrified)
- ร่างกายกลายเป็นวัตถุแข็ง **น้ำหนักเพิ่ม 10 เท่า** และหยุดแก่
- **Incapacitated** + ขยับไม่ได้ + ไม่รับรู้อะไรรอบตัว
- **ล้มเหลวอัตโนมัติใน STR Save และ DEX Save** • **ศัตรูตีเราได้เปรียบ**
- ได้ **Resistance ต่อดาเมจทุกประเภท** และ **Immunity ต่อ Poison และโรค** (พิษที่มีอยู่แล้วหยุดทำงานชั่วคราว)

### ถูกพิษ (Poisoned)
- **ทอย Attack Roll เสียเปรียบทั้งหมด**
- **ทอย Ability Check เสียเปรียบทั้งหมด**
- เป็นสภาวะที่ **ดูเบา แต่กระทบมาก** เพราะโดนทุกการโจมตีและทุกสกิลเช็ค

### ล้มลงนอน (Prone)
- เคลื่อนที่ได้แค่ **คลาน** (ใช้ระยะ 2 เท่า) หรือลุกขึ้น (**ใช้ครึ่งหนึ่งของ Speed**)
- **Attack Roll ของเราเสียเปรียบ**
- **ศัตรูตีเราจากระยะ 5 ฟุต ได้เปรียบ**
- **ศัตรูตีเราจากระยะไกล เสียเปรียบ**

### ถูกตรึง (Restrained)
- **Speed = 0**
- **Attack Roll ของเราเสียเปรียบ** • **ศัตรูตีเราได้เปรียบ**
- **DEX Save เสียเปรียบ** อันตรายมากเวลาโดน Fireball

### มึนงง (Stunned)
- **Incapacitated** + ขยับไม่ได้ + พูดได้แค่ติดขัด
- **ล้มเหลวอัตโนมัติใน STR Save และ DEX Save**
- **ศัตรูตีเราได้เปรียบ**

### หมดสติ (Unconscious)
- **Incapacitated** + **Prone** + ขยับไม่ได้ + พูดไม่ได้ + ไม่รับรู้อะไรเลย
- ทำของหลุดมือทุกอย่าง
- **ล้มเหลวอัตโนมัติใน STR Save และ DEX Save**
- **ศัตรูตีเราได้เปรียบ**
- **ศัตรูที่ตีเราในระยะ 5 ฟุต = Critical Hit ทุกครั้ง**

## ความอ่อนล้า (Exhaustion) — กฎใหม่ 2024 ที่ง่ายขึ้นมาก

> **เปลี่ยนจากกฎ 2014 ทั้งหมด** — เมื่อก่อนแต่ละระดับให้ผลต่างกัน ตอนนี้ **ผลเดียวกันแต่คูณตามระดับ**

### ผลของ Exhaustion

ทุกระดับที่มี จะได้ผล **สะสม** ดังนี้:

| ผล | คำนวณ |
|---|---|
| **ลบทุกการทอย d20 Test** | **−2 × ระดับ Exhaustion** |
| **ลด Speed** | **−5 ฟุต × ระดับ Exhaustion** |

### ตารางสรุป

| ระดับ | ผลลบต่อ d20 Test | ผลลบต่อ Speed |
|---|---|---|
| **1** | −2 | −5 ฟุต |
| **2** | −4 | −10 ฟุต |
| **3** | −6 | −15 ฟุต |
| **4** | −8 | −20 ฟุต |
| **5** | −10 | −25 ฟุต |
| **6** | **ตาย** | |

### สาเหตุที่ทำให้เกิด Exhaustion
- อดอาหาร/น้ำ • ไม่ได้นอน • เดินทางหนักเกินไป (Forced March)
- โดนสภาพอากาศรุนแรง • สเปลบางอย่าง • ความสามารถบางอย่างของมอนสเตอร์
- **การถูกชุบชีวิตด้วย Revivify และสเปลชุบชีวิตหลายชนิด**

### วิธีหาย
- **Long Rest 1 ครั้ง ลดลง 1 ระดับ** (ต้องกินอาหารและดื่มน้ำด้วย)
- สเปล **Greater Restoration** ลด 1 ระดับ

## สภาวะที่ผู้เล่นใช้ทำร้ายศัตรูได้บ่อย

| อยากทำอะไร | ใช้อะไร |
|---|---|
| ทำให้ศัตรู **Prone** | Shove (Unarmed Strike), Weapon Mastery **Topple**, สเปล `Grease` |
| ทำให้ศัตรู **Restrained** | สเปล `Entangle`, `Web`, `Ensnaring Strike` |
| ทำให้ศัตรู **Frightened** | `Cause Fear`, ความสามารถของ Barbarian/Paladin/Bard |
| ทำให้ศัตรู **Blinded** | `Blindness/Deafness`, `Fog Cloud` (บังสายตา) |
| ทำให้ศัตรู **Paralyzed** | `Hold Person`, `Hold Monster` |
| ทำให้ศัตรู **Stunned** | Monk `Stunning Strike` |
| ทำให้ศัตรู **Grappled** | Unarmed Strike (Grapple), Weapon Mastery **Push** ใช้ผลักแทน |

> **กลยุทธ์คลาสสิก:** ทำให้ศัตรู **Prone** ก่อน เพื่อนที่ตีระยะประชิดทุกคนได้ **Advantage** ทันที คุ้มค่ามาก
