### แปลงร่าง (Polymorph) **[C]**
**สเปลระดับ 4 · Transmutation**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 60 ฟุต |
| **Components** | V, S, M (ดักแด้ผีเสื้อ) |
| **Duration** | **Concentration, 1 ชั่วโมง** |
| **คลาส** | Bard, Druid, Sorcerer, Wizard |

เป้าหมายทอย **Wisdom Saving Throw** (ถ้ายินยอมก็ไม่ต้องทอย) — **ล้มเหลว = แปลงร่างเป็นสัตว์ (Beast)**
- **CR ของร่างใหม่ต้องไม่เกิน CR หรือเลเวลของเป้าหมาย**
- **ใช้สถิติของสัตว์ทั้งหมด แต่คงบุคลิกและค่า INT / WIS / CHA ไว้**
- **HP ของร่างสัตว์แยกจาก HP จริง** — เมื่อ HP ร่างสัตว์เหลือ 0 **จะกลับร่างเดิมพร้อม HP เดิม**
- **ร่ายเวทและพูดไม่ได้**

> **[แนะนำ]** **ใช้ได้ 2 ทาง:**
> **กับศัตรู** — แปลงบอสเป็นกบ ทำให้มันไร้พิษภัยทั้งการต่อสู้
> **กับเพื่อน** — แปลงเป็น **T-Rex (CR 8)** เพื่อให้มี HP สำรอง 136 และดาเมจมหาศาล

| | |
|---|---|

| **Range** | **500 ฟุต** |

**ระวัง:** ถ้าจุดหมายมีของขวางอยู่ ทั้งคุณและคนที่พาไปรับ **4d6 Force damage** และการวาร์ปล้มเหลว

### เนรเทศ (Banishment) **[C]**
**สเปลระดับ 4 · Abjuration**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 60 ฟุต |
| **Components** | V, S, M (ของที่เกลียดของเป้าหมาย) |
| **Duration** | **Concentration, 1 นาที** |
| **คลาส** | Cleric, Paladin, Sorcerer, Warlock, Wizard |

เป้าหมายทอย **Charisma Saving Throw** — **ล้มเหลว = หายไปสู่มิติกักขัง**
- ระหว่างนั้น **มันทำอะไรไม่ได้เลยและไม่มีใครทำอะไรมันได้**
- **กลับมาที่เดิมเมื่อสเปลจบ**
- **ถ้าเป้าหมายมาจากมิติอื่น (Fiend, Celestial, Elemental, Fey) และสเปลอยู่ครบ 1 นาที มันจะไม่กลับมาเลย**

**ใช้ Slot ระดับสูงกว่า:** เพิ่มเป้าหมาย **+1 ตัว ต่อระดับ**

> **[แนะนำ]** **ตัดบอสออกจากการต่อสู้ 10 รอบ** — ให้ทีมจัดการลูกน้องก่อน

### กำแพงเพลิง (Wall of Fire) **[C]**
**สเปลระดับ 4 · Evocation**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 120 ฟุต |
| **Components** | V, S, M (ฟอสฟอรัสเล็กน้อย) |
| **Duration** | **Concentration, 1 นาที** |
| **คลาส** | Druid, Sorcerer, Wizard |

สร้างกำแพงไฟ **ยาว 60 ฟุต สูง 20 ฟุต หนา 1 นิ้ว** (หรือวงแหวนรัศมี 20 ฟุต):
- สิ่งมีชีวิตที่**เข้ามาในระยะ 10 ฟุตของกำแพง หรือจบเทิร์นตรงนั้น** ทอย **Dexterity Saving Throw**
  **ล้มเหลว = 5d8 Fire** (สำเร็จ = ครึ่ง)
- **เลือกได้ว่าด้านไหนของกำแพงร้อน** (อีกด้านไม่ทำดาเมจ)

**ใช้ Slot ระดับสูงกว่า:** **+1d8 ต่อระดับ**

> ใช้แบ่งสนามรบ หรือปิดทางหนี · **แรงมากเมื่อรวมกับสเปลที่ผลักศัตรูเข้าไป**

### สับสน (Confusion) **[C]**
**สเปลระดับ 4 · Enchantment**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 90 ฟุต (**ทรงกลม 10 ฟุต**) |
| **Components** | V, S, M (เมล็ดถั่วและใบไม้) |
| **Duration** | **Concentration, 1 นาที** |
| **คลาส** | Bard, Druid, Sorcerer, Wizard |

สิ่งมีชีวิตในพื้นที่ทอย **Wisdom Saving Throw** — ล้มเหลว = **ทอย d10 ตอนเริ่มเทิร์นแต่ละครั้ง**

| d10 | ทำอะไร |
|---|---|
| **1** | ไม่ทำอะไรเลยทั้งเทิร์น |
| **2-6** | ไม่ทำอะไร แต่**เคลื่อนที่ไปทิศทางสุ่ม** |
| **7-8** | **ใช้ Attack action โจมตีสิ่งมีชีวิตที่อยู่ใกล้ที่สุดแบบสุ่ม** (อาจเป็นพวกเดียวกัน) |
| **9-10** | ทำอะไรก็ได้ตามปกติ |

ทอย Save ใหม่ได้ตอนจบเทิร์นแต่ละครั้ง

**ใช้ Slot ระดับสูงกว่า:** **รัศมี +5 ฟุต ต่อระดับ**

### กำแพงพลัง (Wall of Force) **[C]**
**สเปลระดับ 5 · Evocation**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 120 ฟุต |
| **Components** | V, S, M (ผงจากอัญมณีใส) |
| **Duration** | **Concentration, 10 นาที** |
| **คลาส** | Wizard |

สร้างกำแพงพลังใส:
- **แผง 10 แผ่นขนาด 10×10 ฟุต** หรือ **โดมหรือทรงกลมรัศมี 10 ฟุต**
- **ไม่มีอะไรผ่านได้เลย** — สิ่งมีชีวิต วัตถุ และการโจมตีกายภาพ
- **ทำลายไม่ได้ด้วยดาเมจใด ๆ**
- ยกเลิกได้ด้วย **`Disintegrate`** หรือ **`Dispel Magic`** เท่านั้น

> **[แนะนำ]** **สเปลป้องกันและควบคุมที่ดีที่สุดในเกม**
> ขังบอสไว้ในทรงกลม · ตัดกองทัพศัตรูออกเป็นสองส่วน · ปิดทางหนี · ป้องกันทีมจากดาเมจพื้นที่

- **สั่งให้ทำอะไรก็ได้** ด้วยการสื่อสารทางจิต
- **ใช้ Action เพื่อควบคุมมันโดยสมบูรณ์ในเทิร์นนั้น**
- **ระวัง:** **ถ้ามันได้รับดาเมจ ให้ทอย Save ใหม่ทันที**

**ใช้ Slot ระดับสูงกว่า:** ระดับ 6 = 10 นาที · ระดับ 7 = 1 ชั่วโมง · ระดับ 8+ = 8 ชั่วโมง

> **[แนะนำ]** เป็นทางเดียวที่แก้ **HP สูงสุดที่ถูกลดถาวร** และ **Petrified** ได้

## ตารางสรุปสเปลระดับ 4-5 ตามคลาส

| คลาส | ระดับ 4 | ระดับ 5 |
|---|---|---|
| **Bard** | `Polymorph` · `Greater Invisibility` | `Synaptic Static` · `Greater Restoration` |
| **Cleric** | `Death Ward` · `Banishment` · `Freedom of Movement` | `Greater Restoration` · `Mass Cure Wounds` · `Raise Dead` |
| **Druid** | `Polymorph` · `Wall of Fire` · `Freedom of Movement` | `Greater Restoration` · `Wall of Stone` |
| **Paladin** | `Death Ward` · `Banishment` | `Greater Restoration` (ผ่าน Subclass) |
| **Ranger** | `Freedom of Movement` · `Stoneskin` | `Steel Wind Strike` · `Greater Restoration` |
| **Sorcerer** | `Polymorph` · `Greater Invisibility` · `Banishment` | `Synaptic Static` · `Hold Monster` · `Animate Objects` |
| **Warlock** | `Dimension Door` · `Banishment` | `Synaptic Static` · `Hold Monster` |
| **Wizard** | `Polymorph` · `Greater Invisibility` · `Wall of Fire` | `Wall of Force` · `Animate Objects` · `Bigby's Hand` |

## สรุปสเปลระดับ 4-5 ในหนึ่งบรรทัด

> **ระดับ 4 คือระดับที่สเปลเริ่ม "ลบศัตรูออกจากการต่อสู้" ได้ (`Polymorph`, `Banishment`) และระดับ 5 คือระดับที่ควบคุมสนามรบทั้งหมดได้ (`Wall of Force`)**
