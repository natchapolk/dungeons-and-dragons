## ไฟล์นี้ต่างจากรายการเวทในไฟล์คลาสยังไง

| ที่ไหน | มีอะไร |
|---|---|
| **ไฟล์คลาส** (เช่น [Wizard](../04-classes/wizard.md)) | **รายชื่อสเปลทั้งหมด**ที่คลาสนั้นเข้าถึงได้ พร้อมคำอธิบาย 1 บรรทัด — ใช้ตอน **เลือกว่าจะเอาสเปลอะไร** |
| **โฟลเดอร์นี้** | **รายละเอียดเต็มของสเปลที่ใช้บ่อยที่สุด** — Casting Time, Range, Components, Duration, ผลเต็ม — ใช้ตอน **ร่ายจริงในเกม** |

> **ที่นี่รวมสเปลที่ใช้บ่อยที่สุดประมาณ 140 อัน** ไม่ใช่ทั้งหมดใน PHB
> ถ้าหาสเปลที่ต้องการไม่เจอ ให้ดูรายชื่อในไฟล์คลาส แล้วเช็ครายละเอียดจากหนังสือต้นฉบับ

## วิธีอ่านรายละเอียดสเปล

```
ชื่อไทย (Spell Name)
สเปลระดับ X · สำนักเวท

Casting Time เวลาที่ใช้ร่าย (Action / Bonus Action / Reaction / นาที)
Range ระยะ
Components องค์ประกอบที่ต้องใช้ — V (เสียง) S (ท่าทาง) M (วัตถุ)
Duration ระยะเวลาที่ผลคงอยู่
คลาสที่ใช้ได้ คลาสไหนเข้าถึงสเปลนี้ได้

[คำอธิบายผลของสเปล]

ใช้ Slot ระดับสูงกว่า: แรงขึ้นยังไง
```

### สัญลักษณ์ที่ใช้

| สัญลักษณ์ | ความหมาย |
|---|---|
| **[C]** | **Concentration** — รักษาได้ทีละ 1 สเปล · โดนตีต้องทอย CON Save |
| **[R]** | **Ritual** — ร่ายช้าลง 10 นาที แต่ **ไม่เสีย Spell Slot** |
| **V** | Verbal — ต้องพูดออกเสียง (ร่ายไม่ได้ถ้าถูกปิดปากหรืออยู่ใน `Silence`) |
| **S** | Somatic — ต้องขยับมือ (**ต้องมีมือว่างอย่างน้อย 1 ข้าง**) |
| **M** | Material — ต้องมีวัตถุ (ใช้ Spellcasting Focus แทนได้ ยกเว้นที่ระบุราคา) |
| **[แนะนำ]** | สเปลที่คุ้มค่าที่สุดในระดับนั้น |

## กฎการร่ายเวทที่ต้องจำ (สรุปเร็ว)

| กฎ | รายละเอียด |
|---|---|
| **Concentration ทีละ 1 สเปล** | ร่ายอันใหม่ = อันเก่าหายทันที |
| **โดนดาเมจ = ทอย CON Save** | **DC = 10 หรือครึ่งหนึ่งของดาเมจ แล้วแต่ว่าอันไหนมากกว่า** |
| **Bonus Action + สเปลอื่น** | ถ้าร่ายสเปลด้วย Bonus Action **ร่ายสเปลอื่นในเทิร์นเดียวกันไม่ได้** ยกเว้น Cantrip ที่ใช้ Action |
| **Slot เสียไม่ว่าผลจะเป็นยังไง** | ศัตรู Save ผ่าน Slot ก็หายไปแล้ว |
| **Cantrip ไม่แรงขึ้นจาก Slot** | แต่แรงขึ้นเองที่ **เลเวลตัวละคร 5, 11, 17** |

อ่านกฎเต็มที่ [กฎการร่ายเวท](../01-basics/07-spellcasting-rules.md)
