> **ได้ที่เลเวล 5 (Full Caster)** — เป็นจุดที่เกมเปลี่ยนไปมากที่สุด เพราะสายเวทได้ `Fireball` และ `Counterspell`

## สเปลที่เปลี่ยนเกม

---

### ลูกไฟ (Fireball)
**สเปลระดับ 3 · Evocation**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | **150 ฟุต** (**ทรงกลมรัศมี 20 ฟุต**) |
| **Components** | V, S, M (มูลค้างคาวและกำมะถัน) |
| **Duration** | ทันที |
| **คลาส** | Sorcerer, Wizard (Cleric สาย Light Domain) |

สิ่งมีชีวิตในพื้นที่ทอย **Dexterity Saving Throw** — **ล้มเหลว = 8d6 Fire damage** (สำเร็จ = ครึ่ง)
ไฟลามรอบมุมและจุดวัตถุที่ไม่มีใครถือให้ติดไฟ

**ใช้ Slot ระดับสูงกว่า:** **+1d6 ต่อระดับ**

> **[แนะนำ]** **สเปลที่โด่งดังที่สุดในเกม** — รัศมี 20 ฟุตครอบคลุมประมาณ **8 ช่องบนแผนที่ตาราง**
> **ระวัง:** **ระวังโดนเพื่อน** — ยกเว้นถ้าคุณเป็น **Evoker** (Sculpt Spells) หรือมี Metamagic **`Careful Spell`**

---

### ขัดขวางเวท (Counterspell)
**สเปลระดับ 3 · Abjuration**

| | |
|---|---|
| **Casting Time** | **Reaction** — เมื่อเห็นสิ่งมีชีวิตในระยะ 60 ฟุตกำลังร่ายเวท |
| **Range** | 60 ฟุต |
| **Components** | S |
| **Duration** | ทันที |
| **คลาส** | Sorcerer, Warlock, Wizard (Bard ผ่าน Magical Secrets) |

ผู้ร่ายเวทเป้าหมายทอย **Constitution Saving Throw** เทียบ **Spell Save DC ของคุณ**
**ล้มเหลว = สเปลนั้นล้มเหลว และ Slot ของมันเสียไปเปล่า ๆ**

**ใช้ Slot ระดับสูงกว่า:** เป้าหมาย **เสียเปรียบในการทอย Save** ถ้าคุณใช้ Slot สูงกว่าระดับสเปลของมัน

> **[แนะนำ]** **สเปลป้องกันที่สำคัญที่สุดในเกมระดับสูง** — หยุด `Fireball`, `Hold Person`, หรือแม้แต่ `Power Word Kill`
> **เก็บ Slot ระดับ 3 ไว้ 1 ช่องเสมอสำหรับ Counterspell**

### ลวดลายสะกดจิต (Hypnotic Pattern) **[C]**
**สเปลระดับ 3 · Illusion**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 120 ฟุต (**ลูกบาศก์ 30 ฟุต**) |
| **Components** | S, M (ธูปหรือคริสตัล) |
| **Duration** | **Concentration, 1 นาที** |
| **คลาส** | Bard, Sorcerer, Warlock, Wizard |

สิ่งมีชีวิตในพื้นที่ที่มองเห็นลวดลาย ทอย **Wisdom Saving Throw**
**ล้มเหลว = Charmed และ Incapacitated และ Speed เป็น 0**
สภาวะจบเมื่อ **มันได้รับดาเมจ** หรือมีคนใช้ Action ปลุกมัน

> **[แนะนำ]** **สเปลควบคุมที่ดีที่สุดในเกม** — หยุดศัตรูทั้งกลุ่มได้ในครั้งเดียว
> ไม่มีองค์ประกอบ Verbal จึงร่ายเงียบ ๆ ได้
> **ระวัง:** **บอกเพื่อนว่าอย่าตีศัตรูที่โดนสะกด** ไม่งั้นสภาวะจะหลุด

### วิญญาณผู้พิทักษ์ (Spirit Guardians) **[C]**
**สเปลระดับ 3 · Conjuration**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | Self (**รัศมี 15 ฟุต**) |
| **Components** | V, S, M (สัญลักษณ์ศักดิ์สิทธิ์) |
| **Duration** | **Concentration, 10 นาที** |
| **คลาส** | Cleric |

วิญญาณลอยรอบตัวคุณในรัศมี 15 ฟุต (เคลื่อนที่ตามคุณ):
- **ศัตรูในพื้นที่: Speed ลดลงครึ่งหนึ่ง**
- **ศัตรูที่เข้ามาหรือเริ่มเทิร์นในพื้นที่** ทอย **Wisdom Saving Throw**
  **ล้มเหลว = 3d8 Radiant หรือ Necrotic damage** (สำเร็จ = ครึ่ง)

**ใช้ Slot ระดับสูงกว่า:** **+1d8 ต่อระดับ**

> **[แนะนำ]** **สเปลที่ดีที่สุดของ Cleric** — เดินเข้าไปกลางวงศัตรูแล้วทำดาเมจทุกเทิร์นโดยไม่ต้องทำอะไรเพิ่ม
> คงอยู่ **10 นาที** จึงครอบคลุมการต่อสู้ทั้งหมด

### เร่งความเร็ว (Haste) **[C]**
**สเปลระดับ 3 · Transmutation**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 30 ฟุต |
| **Components** | V, S, M (เศษรากชะเอมและขนไก่) |
| **Duration** | **Concentration, 1 นาที** |
| **คลาส** | Sorcerer, Wizard |

เป้าหมาย 1 ตัวได้ตลอดระยะเวลา:
- **Speed เพิ่มเป็น 2 เท่า**
- **+2 AC**
- **Advantage ในการทอย Dexterity Saving Throw**
- **Action เพิ่ม 1 ครั้งต่อเทิร์น** (ใช้ได้เฉพาะ **Attack 1 ครั้ง, Dash, Disengage, Hide, หรือ Utilize**)

**ระวัง:** **เมื่อสเปลจบ เป้าหมายจะ Incapacitated และ Speed เป็น 0 ในเทิร์นถัดไป** (เหนื่อยล้า)

> **[แนะนำ]** ร่ายใส่ **Fighter หรือ Paladin** — Action เพิ่มทำให้ดาเมจของทีมพุ่งขึ้นมาก
> **ระวัง:** **ถ้าเสีย Concentration เป้าหมายจะเสียเทิร์น** — ระวังให้ดี

| **Duration** | **Concentration, 10 นาที** |
| **คลาส** | Bard, Sorcerer, Warlock, Wizard |

สร้างภาพลวงตาที่มี **ภาพ เสียง กลิ่น และอุณหภูมิ** ครบถ้วน
**Action ทุกเทิร์น: ย้ายภาพและเปลี่ยนพฤติกรรมของมันได้**
ผู้ที่สงสัยใช้ **Action ตรวจสอบด้วย Investigation** เทียบ Spell Save DC

> **ระวัง:** **จับต้องไม่ได้** — มือทะลุผ่าน · **ถ้าใช้ Slot ระดับ 6 ขึ้นไป จะคงอยู่จนกว่าจะยกเลิก ไม่ต้อง Concentration**

ระหว่างอยู่ในนั้น **ไม่มีอะไรทำอันตรายคุณได้เลย** และคุณกลับมาเมื่อเริ่มเทิร์นถัดไป

> ประมาณ 50% ที่ศัตรูจะทำอะไรคุณไม่ได้เลยในแต่ละรอบ

### เรียกฝูงสัตว์ (Conjure Animals) **[C]**
**สเปลระดับ 3 · Conjuration**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 60 ฟุต (**พื้นที่ 10 ฟุตรอบคุณ**) |

| **Duration** | **Concentration, 10 นาที** |
| **คลาส** | Druid, Ranger |

เรียกวิญญาณสัตว์ป่ามาห้อมล้อม:
- **ศัตรูที่เข้ามาหรือเริ่มเทิร์นในพื้นที่** ทอย **Dexterity Saving Throw** — **ล้มเหลว = 2d8 Slashing** (สำเร็จ = ครึ่ง)
- **พื้นที่เป็น Difficult Terrain สำหรับศัตรู**
- **คุณและเพื่อนได้ Speed +10 ฟุต ขณะอยู่ในพื้นที่**

**ใช้ Slot ระดับสูงกว่า:** **+1d8 และรัศมี +5 ฟุต ต่อระดับ**

> **กฎ 2024 เปลี่ยนจากการเรียกสัตว์จริงเป็นพื้นที่เอฟเฟกต์** ทำให้เล่นเร็วขึ้นมาก

### เรียกสายฟ้า (Call Lightning) **[C]**
**สเปลระดับ 3 · Conjuration**

| | |

- สิ่งมีชีวิตในรัศมี 5 ฟุตจากจุดนั้น ทอย **Dexterity Saving Throw** — **ล้มเหลว = 3d10 Lightning** (สำเร็จ = ครึ่ง)

> **[แนะนำ]** **ยิงซ้ำได้ทุกเทิร์นโดยไม่เสีย Slot เพิ่ม** — ดาเมจรวมสูงมากถ้าการต่อสู้ยืดเยื้อ
