### ภาพสะท้อน (Mirror Image)
**สเปลระดับ 2 · Illusion**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | 1 นาที |
| **คลาส** | Sorcerer, Warlock, Wizard |

สร้าง **ภาพลวงตาของตัวเอง 3 ตัว** ที่เคลื่อนไหวตามคุณ

เมื่อมีคนโจมตีคุณ ให้**ทอย d20** เพื่อดูว่าโดนภาพหรือตัวจริง:
| จำนวนภาพที่เหลือ | โดนภาพถ้าทอยได้ |
|---|---|
| 3 ภาพ | **6 ขึ้นไป** |
| 2 ภาพ | **8 ขึ้นไป** |
| 1 ภาพ | **11 ขึ้นไป** |

ภาพมี **AC = 10 + DEX modifier ของคุณ** — ถ้าการโจมตีถึง AC นั้น **ภาพหายไป 1 ตัว**

> **[แนะนำ]** ลดโอกาสถูกตีได้มากตลอด 10 รอบ · ใช้ไม่ได้กับศัตรูที่มี **Blindsight หรือ Truesight**

### ตรึงมนุษย์ (Hold Person) **[C]**
**สเปลระดับ 2 · Enchantment**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 60 ฟุต |
| **Components** | V, S, M (ชิ้นเหล็กตรง) |
| **Duration** | **Concentration, 1 นาที** |
| **คลาส** | Bard, Cleric, Druid, Sorcerer, Warlock, Wizard |

เลือก **Humanoid 1 ตัว** — ทอย **Wisdom Saving Throw**
**ล้มเหลว = Paralyzed** (ทอยใหม่ได้ตอนจบเทิร์นของมันแต่ละครั้ง)

**ใช้ Slot ระดับสูงกว่า:** เพิ่มเป้าหมาย **+1 ตัว ต่อระดับ**

> **[แนะนำ]** **Paralyzed คือสภาวะที่แรงที่สุดในเกม:**
> - ล้มเหลวอัตโนมัติใน STR และ DEX Save
> - **ศัตรูตีมันจากระยะ 5 ฟุต = Critical Hit ทุกครั้ง**
> **ระวัง:** ใช้กับ Humanoid เท่านั้น — มอนสเตอร์หลายชนิดไม่ใช่ Humanoid

### ใยแมงมุม (Web) **[C]**
**สเปลระดับ 2 · Conjuration**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | 60 ฟุต (**ลูกบาศก์ 20 ฟุต**) |
| **Components** | V, S, M (ใยแมงมุมเล็กน้อย) |
| **Duration** | **Concentration, 1 ชั่วโมง** |
| **คลาส** | Sorcerer, Wizard |

พื้นที่เต็มไปด้วยใยเหนียว:
- **Difficult Terrain** และ **Lightly Obscured**
- สิ่งมีชีวิตที่เข้ามาหรือจบเทิร์นในนั้น ทอย **Dexterity Saving Throw** — **ล้มเหลว = Restrained**
- หลุดได้ด้วย **Action + Strength Check**
- **ใยติดไฟได้** — พื้นที่ 5 ฟุตไหม้ใน 1 รอบ ทำ **2d4 Fire** ต่อผู้ที่อยู่ในนั้น

**ต้องมีจุดยึด** (ผนัง เสา ต้นไม้) ไม่งั้นใยจะยุบตัว

> **[แนะนำ]** สเปลควบคุมพื้นที่ที่คุ้มที่สุดในระดับ 2 — คงอยู่ถึง 1 ชั่วโมง

> **[แนะนำ]** **ไม่ต้อง Concentration** — ดาเมจฟรีทุกเทิร์นตลอด 10 นาที และยังร่ายสเปลอื่นได้พร้อมกัน
