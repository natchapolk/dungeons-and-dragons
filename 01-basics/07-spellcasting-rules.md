# กฎการร่ายเวท (Spellcasting Rules)

[กลับสารบัญ](../README.md)

---

## คำศัพท์พื้นฐาน

| คำ | ความหมาย |
|---|---|
| **คาถา/เวทมนตร์ (Spell)** | เวทที่ต้องใช้ Spell Slot |
| **เวทระดับ 0 (Cantrip)** | **ร่ายได้ไม่จำกัดครั้ง ไม่ใช้ Spell Slot** — แรงขึ้นตามเลเวลตัวละคร |
| **ช่องเวท (Spell Slot)** | "กระสุน" ที่ใช้ยิงเวท — หมดแล้วต้องพักถึงจะได้คืน |
| **ระดับเวท (Spell Level)** | 0 (Cantrip) ถึง 9 — **ไม่เกี่ยวกับเลเวลตัวละคร** |
| **ค่าร่ายเวท (Spellcasting Ability)** | ค่าพลังที่คลาสใช้ร่ายเวท (INT/WIS/CHA) |
| **เวทที่เตรียมไว้ (Prepared Spells)** | รายการเวทที่พร้อมใช้ในวันนั้น |
| **สมาธิ (Concentration)** | เวทบางอันต้องรักษาสมาธิเพื่อให้ผลคงอยู่ |
| **ค่ายากต้านเวท (Spell Save DC)** | เลขที่ศัตรูต้องทอย Save ให้ถึง |
| **พิธีกรรม (Ritual)** | ร่ายช้าลง 10 นาที แต่**ไม่เสีย Spell Slot** |

## ค่าร่ายเวทของแต่ละคลาส

| คลาส | Spellcasting Ability | ที่มาของพลัง |
|---|---|---|
| **Wizard** | **INT** (Intelligence) | ศึกษาจากตำรา |
| **Artificer**\* | **INT** | ประดิษฐ์ |
| **Cleric** | **WIS** (Wisdom) | เทพเจ้าประทานให้ |
| **Druid** | **WIS** | ธรรมชาติ |
| **Ranger** | **WIS** | ธรรมชาติ |
| **Bard** | **CHA** (Charisma) | ดนตรีและเสน่ห์ |
| **Paladin** | **CHA** | คำสาบาน |
| **Sorcerer** | **CHA** | สายเลือดโดยกำเนิด |
| **Warlock** | **CHA** | สัญญากับผู้อุปถัมภ์ |

\* Artificer ไม่อยู่ใน PHB 2024 (อยู่ในหนังสือแยก)

### สูตรคำนวณสำคัญ 2 สูตร

```
Spell Save DC = 8 + Proficiency Bonus + Spellcasting Ability modifier
Spell Attack Bonus = Proficiency Bonus + Spellcasting Ability modifier
```

> **ตัวอย่าง:** Wizard เลเวล 5 มี INT 18 (+4), Proficiency +3
> - Spell Save DC = 8 + 3 + 4 = **15**
> - Spell Attack Bonus = 3 + 4 = **+7**

## ช่องเวท (Spell Slots)

### แนวคิดหลัก

- Spell Slot คือ **"กระสุน" ที่แยกตามระดับ**
- ร่ายเวทระดับ 1 ใช้ Slot ระดับ 1 ขึ้นไป
- **ใช้ Slot ระดับสูงกว่าร่ายเวทระดับต่ำได้** (บางเวทจะแรงขึ้น — ดูหัวข้อ "Using a Higher-Level Spell Slot")
- **ใช้ Slot ระดับต่ำร่ายเวทระดับสูง ไม่ได้**
- **Cantrip ไม่ใช้ Slot เลย** — ร่ายกี่ครั้งก็ได้

### ประเภทของผู้ร่ายเวท

| ประเภท | คลาส | Slot สูงสุด |
|---|---|---|
| **Full Caster** | Bard, Cleric, Druid, Sorcerer, Wizard | ระดับ 9 (เลเวล 17) |
| **Half Caster** | Paladin, Ranger | ระดับ 5 (เลเวล 17) — เริ่มมีเวทตั้งแต่เลเวล 1 ในกฎ 2024 |
| **Third Caster** | Eldritch Knight (Fighter), Arcane Trickster (Rogue) | ระดับ 4 (เลเวล 19) |
| **Pact Magic** | **Warlock** | ระบบพิเศษ — ดูด้านล่าง |

### Pact Magic ของ ระบบพิเศษ (Warlock)

Warlock **ไม่ใช้ระบบ Spell Slot ปกติ**:
- มี Slot **น้อยมาก** (1-4 ช่อง)
- แต่ **Slot ทุกช่องเป็นระดับสูงสุดที่มีเสมอ**
- **ฟื้นทุก Short Rest** (ไม่ต้องรอ Long Rest!)

> Warlock เล่นแบบ "ยิงกระสุนแรง ๆ ไม่กี่นัด แล้วพักสั้น ๆ ก็เติมได้"

## การเตรียมเวท (Prepared Spells) — กฎ 2024

> **กฎ 2024 รวมระบบ "Spells Known" กับ "Prepared Spells" เป็นอันเดียว** ทุกคลาสใช้คำว่า **Prepared Spells** หมด

### แต่ละคลาสเตรียมเวทยังไง

| คลาส | วิธี | เปลี่ยนได้เมื่อไหร่ |
|---|---|---|
| **Cleric, Druid, Paladin** | เลือกจาก **รายการเวทของคลาสทั้งหมด** | **ทุกครั้งที่จบ Long Rest** — เปลี่ยนได้ทั้งชุด |
| **Bard, Ranger, Sorcerer, Warlock** | เลือกจากรายการคลาส แต่ **เปลี่ยนได้ทีละ 1 เวท** | **ตอนเลื่อนเลเวล** เปลี่ยนได้ 1 เวท |
| **Wizard** | เตรียมจาก **หนังสือเวท (Spellbook)** ของตัวเอง | **ทุกครั้งที่จบ Long Rest** |

### Spellbook ของ ระบบพิเศษ (Wizard)

- เริ่มเกมด้วยเวทระดับ 1 จำนวน **6 เวท** ในหนังสือ
- **ทุกครั้งที่เลื่อนเลเวล Wizard** เพิ่ม **2 เวท** ฟรี
- **คัดลอกเวทจาก Scroll หรือหนังสือเวทที่หาเจอได้** (เสียเงิน 50 GP และเวลา 2 ชั่วโมง ต่อระดับเวท)
- **แต่เตรียมได้แค่บางส่วน** — จำนวนตามตารางในไฟล์ Wizard

> นี่คือจุดที่ทำให้ Wizard มีเวทหลากหลายที่สุดในเกมระยะยาว

## องค์ประกอบของสเปล (Spell Components)

ทุกสเปลระบุองค์ประกอบที่ต้องใช้:

| ตัวย่อ | ชื่อเต็ม | ความหมาย |
|---|---|---|
| **V** | **เสียง** (Verbal) | ต้องพูดออกเสียง — **ร่ายไม่ได้ถ้าถูก Silenced หรือ Gagged** |
| **S** | **ท่าทาง** (Somatic) | ต้องขยับมือ — **ต้องมีมือว่างอย่างน้อย 1 ข้าง** |
| **M** | **วัตถุ** (Material) | ต้องมีวัตถุประกอบ |

### กฎเรื่อง Material Component

| กรณี | กฎ |
|---|---|
| **ไม่ระบุราคา** (เช่น "ขนนกกา") | ใช้ **ถุงองค์ประกอบ (Component Pouch)** หรือ **ตัวนำเวท (Spellcasting Focus)** แทนได้ |
| **ระบุราคา** (เช่น "ไข่มุกมูลค่า 100 GP") | **ต้องมีของจริง** แทนด้วย Focus ไม่ได้ |
| **ระบุว่า "consumed" (ถูกใช้ไป)** | ของหายไปหลังร่าย — ต้องซื้อใหม่ |

### ตัวนำเวท (Spellcasting Focus) ตามคลาส

| คลาส | Focus ที่ใช้ได้ |
|---|---|
| Wizard, Sorcerer, Warlock | **คทา, ไม้เท้า, ลูกแก้ว, คริสตัล (Arcane Focus)** หรือ Component Pouch |
| Cleric, Paladin | **สัญลักษณ์ศักดิ์สิทธิ์ (Holy Symbol)** — **ติดบนโล่ได้** |
| Druid, Ranger | **กิ่งมิสเซิลโท, ไม้เท้า, ไม้เท้ายอด (Druidic Focus)** |
| Bard | **เครื่องดนตรี (Musical Instrument)** |

> **ข้อควรระวังเรื่องมือ:** สเปลที่มีทั้ง S และ M ต้องมีมือว่าง 1 ข้าง หรือใช้มือที่ถือ Focus ทำท่าได้ **แต่ถ้าถือดาบ+โล่เต็มสองมือจะร่ายไม่ได้** (ยกเว้น Holy Symbol ติดโล่ หรือ War Caster feat)

## เวลาในการร่าย (Casting Time)

| Casting Time | ความหมาย |
|---|---|
| **Action** | ใช้ Action ในเทิร์น — ส่วนใหญ่เป็นแบบนี้ |
| **Bonus Action** | ใช้ Bonus Action — เช่น `Healing Word`, `Misty Step` |
| **Reaction** | ใช้ Reaction เมื่อเกิดเงื่อนไข — เช่น `Shield`, `Counterspell` |
| **1 minute / 10 minutes / 1 hour+** | ร่ายนาน ใช้นอกการต่อสู้ (เช่น `Find Familiar`) |

### กฎสำคัญ: ร่ายเวท 2 ตัวในเทิร์นเดียว

> **กฎ 2024:** ถ้าคุณร่ายสเปลด้วย **Bonus Action** คุณจะ **ร่ายสเปลอื่นในเทิร์นเดียวกันไม่ได้** ยกเว้น **Cantrip ที่มี Casting Time เป็น Action**

| ทำได้ | ทำไม่ได้ |
|---|---|
| `Healing Word` (BA) + `Fire Bolt` (Cantrip, Action) | `Healing Word` (BA) + `Fireball` (Action) |
| `Misty Step` (BA) + `Sacred Flame` (Cantrip) | `Misty Step` (BA) + `Hold Person` (Action) |

## สมาธิ (Concentration) — กฎที่มือใหม่พลาดบ่อยที่สุด

สเปลบางอันมีคำว่า **"Concentration"** ในช่อง Duration — หมายความว่าคุณต้องรักษาสมาธิเพื่อให้ผลคงอยู่

### กฎเหล็ก 3 ข้อ

1. **รักษา Concentration ได้ทีละ 1 สเปลเท่านั้น** — ร่ายอันใหม่ = อันเก่าหายทันที
2. **โดนดาเมจ = ต้องทอย CON Saving Throw**
3. **Incapacitated / หมดสติ / ตาย = Concentration ขาดทันที**

### สูตรทอยรักษา Concentration

```
CON Saving Throw DC = มากกว่าระหว่าง 10 กับ (ครึ่งหนึ่งของดาเมจที่ได้รับ)
```

| ดาเมจที่ได้รับ | DC |
|---|---|
| 1-20 | **10** |
| 22 | 11 |
| 30 | 15 |
| 44 | 22 |

> **ตัวอย่าง:** กำลังรักษา `Bless` อยู่ แล้วโดนตี 14 ดาเมจ ครึ่งหนึ่งคือ 7 ซึ่งน้อยกว่า 10 **ทอย CON Save DC 10**
> ถ้าโดน 30 ดาเมจ ครึ่งคือ 15 **ทอย CON Save DC 15**

### วิธีทำให้ Concentration ทนขึ้น
- ดันค่า **CON ให้สูง**
- เอา Feat **ได้ Advantage ในการทอย Concentration (War Caster)**
- เอา Feat **Resilient (Constitution)** (ได้ Proficiency ใน CON Save)
- ยืนหลังแนวหน้า อย่าให้โดนตี

### สเปล Concentration ยอดนิยม
`Bless`, `Hex`, `Hunter's Mark`, `Hold Person`, `Spirit Guardians`, `Haste`, `Fly`, `Web`, `Faerie Fire`, `Shield of Faith`, `Polymorph`, `Wall of Force`, `Summon` ทุกชนิด

---

## ร่ายด้วย Slot ระดับสูงกว่า (Using a Higher-Level Spell Slot)

สเปลหลายอันมีหัวข้อ **"Using a Higher-Level Spell Slot"** — ระบุว่าถ้าใช้ Slot ที่สูงกว่าจะแรงขึ้นยังไง

> **ตัวอย่าง:** ระดับ 1 (`Magic Missile`) ยิงลูกศร 3 ลูก
> **ใช้ Slot ระดับ 3 ยิง 5 ลูก** (เพิ่ม 1 ลูกต่อระดับที่สูงขึ้น)

> **Cantrip ไม่ได้แรงขึ้นจาก Slot** — แต่แรงขึ้นเองตามเลเวลตัวละคร:
> **เลเวล 5, 11, และ 17** เต๋าดาเมจเพิ่มขึ้น 1 ลูก

---

## การร่ายแบบพิธีกรรม (Ritual Casting)

สเปลบางอันมีแท็ก **[Ritual]**

- ร่ายแบบ Ritual ใช้เวลา **เพิ่มอีก 10 นาที**
- แต่ **ไม่เสีย Spell Slot!**
- กฎ 2024: **สเปลนั้นต้องอยู่ในรายการ Prepared Spells ของคุณ** จึงจะร่ายแบบ Ritual ได้ (ยกเว้น Wizard ที่มี **Ritual Adept** ร่ายจาก Spellbook ได้เลยโดยไม่ต้องเตรียม)

### สเปล Ritual ยอดนิยม
`Detect Magic`, `Identify`, `Comprehend Languages`, `Find Familiar`, `Alarm`, `Speak with Animals`, `Water Breathing`, `Tiny Hut`

## พื้นที่ผลกระทบ (Areas of Effect) 5 รูปแบบ

| รูปแบบ | วัดยังไง | ตัวอย่างสเปล |
|---|---|---|
| **กรวย (Cone)** | ยาวจากจุดกำเนิด ความกว้าง = ความยาว | `Burning Hands` (15 ฟุต) |
| **ลูกบาศก์ (Cube)** | เลือกด้านหนึ่งเป็นจุดกำเนิด | `Thunderwave` (15 ฟุต) |
| **ทรงกระบอก (Cylinder)** | รัศมี + ความสูง | `Call Lightning` |
| **เส้นตรง (Line)** | ยาว × กว้าง | `Lightning Bolt` (100×5 ฟุต) |
| **ทรงกลม (Sphere)** | รัศมีจากจุดศูนย์กลาง | `Fireball` (20 ฟุต) |

> **1 ช่องบนแผนที่ตาราง = 5 ฟุต** — `Fireball` รัศมี 20 ฟุต = วงกลมกว้าง 8 ช่อง

## สำนักเวทมนตร์ (Schools of Magic) 8 สำนัก

| สำนัก | ทำอะไร | ตัวอย่าง |
|---|---|---|
| **ป้องกัน (Abjuration)** | ป้องกัน ปัดเป่า ขับไล่ | `Shield`, `Counterspell`, `Dispel Magic` |
| **เรียก (Conjuration)** | เรียกสิ่งของ/สิ่งมีชีวิต ย้ายที่ | `Misty Step`, `Fog Cloud`, `Summon` |
| **ทำนาย (Divination)** | หาความจริง มองอนาคต | `Detect Magic`, `Identify`, `Scrying` |
| **สะกดจิต (Enchantment)** | ควบคุมจิตใจ | `Charm Person`, `Hold Person`, `Sleep` |
| **เรียกพลัง (Evocation)** | ดาเมจล้วน ๆ | `Fireball`, `Magic Missile`, `Cure Wounds` |
| **ภาพลวงตา (Illusion)** | หลอกประสาทสัมผัส | `Minor Illusion`, `Invisibility`, `Mirror Image` |
| **เนโครแมนซี (Necromancy)** | ควบคุมชีวิตและความตาย | `Animate Dead`, `Chill Touch`, `Revivify` |
| **แปรสภาพ (Transmutation)** | เปลี่ยนสภาพสิ่งของ | `Polymorph`, `Fly`, `Haste` |

## คำถามที่มือใหม่ถามบ่อย

| คำถาม | คำตอบ |
|---|---|
| **ร่ายเวทตอนศัตรูอยู่ประชิดได้ไหม?** | ได้ ไม่มีบทลงโทษ (ไม่เหมือนบางเกม) |
| **สเปลถูก Reaction ขัดจังหวะได้ไหม?** | ได้ ด้วย `Counterspell` |
| **ร่ายเวทใส่ตัวเองได้ไหม?** | ได้ ถ้าสเปลระบุว่าเป้าหมายเป็น "a creature" |
| **Cantrip แรงขึ้นตามเลเวลไหน?** | เลเวลตัวละคร **5, 11, 17** |
| **มีเวทเตรียมไว้ 4 อัน + Slot 2 ช่อง = ร่ายได้กี่ครั้ง?** | **2 ครั้ง** — เลือกได้ว่าจะร่ายอันไหนจาก 4 อัน |
| **ร่ายเวทเดิมซ้ำได้ไหม?** | ได้ ตราบที่ยังมี Slot เหลือ |
| **ถ้าเป้าหมายทอย Save สำเร็จ Slot เสียไหม?** | **เสีย** — Slot ใช้ไปตอนร่าย ไม่ว่าผลจะเป็นยังไง |
| **ร่ายเวทตอนถูก Grappled ได้ไหม?** | ได้ (Grappled ไม่ใช่ Incapacitated) |
