# ลูกเต๋าและการทอย (Dice & Rolls)

[กลับสารบัญ](../README.md)

## ลูกเต๋า 7 ลูกในชุดมาตรฐาน

ตัวอักษร **d** ย่อมาจาก **die/dice (ลูกเต๋า)** เลขข้างหลังคือจำนวนหน้า

| เต๋า | ชื่อเรียก | หน้า | ใช้ทำอะไรบ่อยที่สุด |
|---|---|---|---|
| **d4** | ดีสี่ (พีระมิด) | 1-4 | ดาเมจมีดสั้น, Healing Word, Guidance |
| **d6** | ดีหก (ลูกเต๋าปกติ) | 1-6 | ดาเมจดาบสั้น, Sneak Attack, Fireball |
| **d8** | ดีแปด | 1-8 | ดาเมจดาบยาว, Hit Dice ของหลายคลาส |
| **d10** | ดีสิบ | 1-10 (หรือ 0-9) | ดาเมจธนู, Hit Dice ของ Fighter |
| **d12** | ดีสิบสอง | 1-12 | ดาเมจขวานใหญ่, Hit Dice ของ Barbarian |
| **d20** | **ดียี่สิบ** | 1-20 | **สำคัญที่สุด** — ใช้ทุกการทดสอบในเกม |
| **d100 (d%)** | ดีร้อย | 1-100 | ทอยสุ่มตารางของ, เอฟเฟกต์สุ่ม |

### วิธีทอย d100

ใช้ d10 สองลูก: ลูกหนึ่งเป็น **หลักสิบ** อีกลูกเป็น **หลักหน่วย**
- ทอยได้ `7` (หลักสิบ) กับ `3` (หลักหน่วย) = **73**
- ทอยได้ `0` กับ `0` = **100** (ไม่ใช่ 0)

## วิธีอ่านสูตรเต๋า (Dice Notation)

รูปแบบ: **`[จำนวนลูก]d[หน้า] + [ตัวบวก]`**

| สูตร | อ่านว่า | แปลว่า |
|---|---|---|
| `1d20` | หนึ่งดียี่สิบ | ทอย d20 หนึ่งลูก |
| `2d6` | สองดีหก | ทอย d6 สองลูก **แล้วบวกกัน** (ได้ 2-12) |
| `1d8 + 3` | หนึ่งดีแปดบวกสาม | ทอย d8 แล้วบวก 3 (ได้ 4-11) |
| `8d6` | แปดดีหก | ทอย d6 แปดลูกบวกกัน (Fireball!) |
| `4d6 drop lowest` | สี่ดีหกตัดต่ำสุด | ทอย d6 สี่ลูก ตัดลูกที่น้อยสุดทิ้ง บวก 3 ลูกที่เหลือ |

> ถ้าไม่มีเต๋าครบ ทอยลูกเดิมซ้ำหลายครั้งก็ได้ผลเหมือนกัน

## D20 Test — หัวใจของกฎ D&D 2024

ในกฎ 2024 มีคำเรียกรวมว่า **การทดสอบด้วย d20 (D20 Test)** ซึ่งครอบคลุมทั้ง 3 อย่างนี้:

```
D20 Test (การทดสอบด้วย d20) แบ่งเป็น 3 อย่าง

  1. Ability Check การทอยทดสอบความสามารถ
  2. Saving Throw การทอยต้านทาน
  3. Attack Roll การทอยโจมตี

ทั้ง 3 อย่างใช้สูตรเดียวกัน ต่างกันแค่เลขเป้าหมายที่เทียบ
```

**สูตรเดียวกันหมด:**

```
1d20 + Ability Modifier + Proficiency Bonus (ถ้าถนัด) + โบนัส/ลบอื่น ๆ
```

แล้วเทียบกับเลขเป้าหมาย:
- **Ability Check / Saving Throw** เทียบกับ **Difficulty Class / ค่าความยาก (DC)**
- **Attack Roll** เทียบกับ **Armor Class / ค่าป้องกัน (AC)** ของเป้าหมาย

**ทอยได้เท่ากับหรือมากกว่าเลขเป้าหมาย = สำเร็จ**

## DC — ค่าความยาก (Difficulty Class)

DM เป็นคนกำหนด DC ตามความยากของสิ่งที่ทำ

| DC | ระดับความยาก (ไทย) | ตัวอย่าง |
|---|---|---|
| **5** | Very Easy — ง่ายมาก | ปีนบันไดเชือกที่มั่นคง |
| **10** | Easy — ง่าย | กระโดดข้ามลำธารแคบ |
| **15** | Medium — ปานกลาง | สะเดาะกุญแจทั่วไป, โน้มน้าวยามที่ลังเล |
| **20** | Hard — ยาก | ปีนกำแพงเรียบเปียกฝน |
| **25** | Very Hard — ยากมาก | หลอกพ่อค้าเจ้าเล่ห์ที่ระแวงอยู่แล้ว |
| **30** | Nearly Impossible — แทบเป็นไปไม่ได้ | กระโดดจากหลังคาข้ามถนนกว้าง |

> **ผู้เล่นไม่ต้องรู้ DC ล่วงหน้า** — DM อาจบอกหรือไม่บอกก็ได้

## ได้เปรียบ / เสียเปรียบ (Advantage & Disadvantage)

กลไกที่ใช้บ่อยที่สุดในเกม และเข้าใจง่ายมาก:

| กลไก | วิธีทำ |
|---|---|
| **ได้เปรียบ (Advantage)** | ทอย d20 **สองลูก** เอา **ค่าสูงกว่า** |
| **เสียเปรียบ (Disadvantage)** | ทอย d20 **สองลูก** เอา **ค่าต่ำกว่า** |

### กฎสำคัญ 3 ข้อ

1. **ไม่สะสม** — มี Advantage 3 อย่าง ก็ยังทอยแค่ 2 ลูก
2. **หักล้างกัน** — ถ้ามีทั้ง Advantage และ Disadvantage อย่างละอย่างขึ้นไป **หักล้างหมด ทอยลูกเดียวปกติ**
3. ใช้ได้กับ **D20 Test ทุกประเภท**

### ตัวอย่างที่ทำให้ได้ Advantage
- ศัตรูอยู่ในสภาวะ **ล้มลงนอน (Prone)** และเราตีระยะประชิด
- ศัตรูอยู่ในสภาวะ **ถูกตรึง (Restrained)** หรือ **เป็นอัมพาต (Paralyzed)**
- เราโจมตีจากที่ซ่อน (**Unseen / มองไม่เห็น**)
- ใช้ **ช่วยเหลือ (Help action)** จากเพื่อน

### ตัวอย่างที่ทำให้เสีย Disadvantage
- อยู่ในสภาวะ **ถูกพิษ (Poisoned)** หรือ **หวาดกลัว (Frightened)**
- ยิงธนูใส่เป้าหมายที่อยู่ระยะไกลเกิน Normal Range
- โจมตีระยะไกลตอนมีศัตรูประชิดตัวอยู่
- ใส่เกราะหนักที่ไม่มี Proficiency

## Critical Hit & Critical Miss

| ทอยได้ | ชื่อ | ผล |
|---|---|---|
| **d20 ออก 20 พอดี** (Natural 20) | **Critical Hit** — คริติคอล | ตีโดนแน่นอน **และทอยเต๋าดาเมจสองเท่า** |
| **d20 ออก 1 พอดี** (Natural 1) | **Critical Miss** — พลาดสนิท | พลาดแน่นอน ไม่ว่าจะบวกเยอะแค่ไหน |

### วิธีคิดดาเมจ Critical Hit

**ทอยเต๋าดาเมจ 2 เท่า แต่ตัวบวกคงเดิม (ไม่คูณสอง)**

> ตัวอย่าง: ดาบยาว `1d8 + 4`
> - ตีปกติ = `1d8 + 4`
> - **Critical Hit = `2d8 + 4`** ไม่ใช่ `(1d8+4) × 2`

> **Nat 20 / Nat 1 ใช้กับ Attack Roll เท่านั้น** ในกฎ 2024 การทอย Ability Check หรือ Saving Throw ที่ออก 20 หรือ 1 **ไม่มีผลพิเศษ** (แต่ DM บางโต๊ะอาจตั้ง House Rule เอง)

## แรงบันดาลใจวีรบุรุษ (Heroic Inspiration)

กฎ 2024 เปลี่ยนชื่อจาก "Inspiration" เป็น **Heroic Inspiration** และใช้ง่ายขึ้น:

- DM จะให้เมื่อคุณ **เล่นบทบาทได้ดี ตัดสินใจกล้าหาญ หรือทำอะไรสนุก ๆ**
- **Human** ได้ฟรีทุกครั้งที่จบ Long Rest
- **ใช้ได้:** ทอย d20 ใหม่ 1 ครั้ง (ทอยแล้วต้องใช้ผลใหม่)
- **เก็บได้ครั้งละ 1 อันเท่านั้น** — ถ้ามีอยู่แล้วแล้วได้อีก อันใหม่จะหายไป (แต่คุณสามารถยกให้เพื่อนแทนได้)

## โบนัสความชำนาญ (Proficiency Bonus)

เลขที่บวกเพิ่มเข้าไปใน "สิ่งที่ตัวละครเราถนัด" ขึ้นกับ **เลเวลตัวละคร** (ไม่ใช่เลเวลคลาส)

| เลเวลตัวละคร | Proficiency Bonus |
|---|---|
| 1-4 | **+2** |
| 5-8 | **+3** |
| 9-12 | **+4** |
| 13-16 | **+5** |
| 17-20 | **+6** |

### บวกเมื่อไหร่?

| บวก | ไม่บวก |
|---|---|
| Skill ที่เรามี Proficiency | Skill ที่ไม่มี Proficiency |
| Saving Throw ที่คลาสเราถนัด | Saving Throw อื่น ๆ |
| Attack Roll ด้วยอาวุธที่ถนัด | Attack Roll ด้วยอาวุธที่ไม่ถนัด |
| Attack Roll ของสเปล | **ดาเมจ (Damage Roll) — ไม่เคยบวก Proficiency** |
| การใช้ Tool ที่ถนัด | |

### ความเชี่ยวชาญ (Expertise)

บาง Feature (เช่นของ Rogue และ Bard) ให้ **Expertise** = **บวก Proficiency Bonus สองเท่า** ใน Skill นั้น

> Rogue เลเวล 5 มี DEX +4, Proficiency +3, มี Expertise ใน Stealth
> `1d20 + 4 + (3×2) = 1d20 + 10`
