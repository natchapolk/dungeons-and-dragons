# ค่าพลังพื้นฐาน 6 ค่า (Ability Scores)

[กลับสารบัญ](../README.md)

---

## ค่าพลัง 6 ค่า (The Six Abilities)

ทุกสิ่งที่ตัวละครทำได้ในเกม วัดด้วยตัวเลข 6 ตัวนี้

| ตัวย่อ | ชื่อเต็ม | วัดอะไร |
|---|---|---|
| **STR** | **พละกำลัง** (Strength) | แรงกาย ยกของ ฟาดฟัน ผลักดัน |
| **DEX** | **ความคล่องแคล่ว** (Dexterity) | ความว่องไว ทรงตัว หลบหลีก ความแม่นมือ |
| **CON** | **ความอึด** (Constitution) | ความทนทาน สุขภาพ พลังชีวิต |
| **INT** | **สติปัญญา** (Intelligence) | ความรู้ ความจำ การใช้เหตุผล |
| **WIS** | **ปัญญาญาณ** (Wisdom) | การสังเกต สัญชาตญาณ ความรู้เท่าทัน |
| **CHA** | **เสน่ห์** (Charisma) | บุคลิก ความมั่นใจ การโน้มน้าวคน |

> **จุดที่มือใหม่สับสนบ่อย: INT ≠ WIS**
> - **สติปัญญา (INT)** = "ฉัน**รู้**ว่าเห็ดชนิดนี้มีพิษ" (ความรู้จากตำรา)
> - **ปัญญาญาณ (WIS)** = "ฉัน**รู้สึก**ว่าคนนี้กำลังโกหก" (การสังเกตและสัญชาตญาณ)

## Ability Modifier — ตัวเลขที่ใช้จริง

**ค่า Ability Score ดิบ (เช่น 16) ไม่ได้เอาไปบวกตรง ๆ** ต้องแปลงเป็น **ตัวปรับค่า (Modifier)** ก่อน

### สูตร

```
Modifier = ปัดลง( (Ability Score − 10) ÷ 2 )
```

### ตารางแปลงค่า (จำตารางนี้ก็พอ)

| Score | Modifier | | Score | Modifier |
|---|---|---|---|---|
| 1 | **−5** | | 14-15 | **+2** |
| 2-3 | **−4** | | 16-17 | **+3** |
| 4-5 | **−3** | | 18-19 | **+4** |
| 6-7 | **−2** | | 20-21 | **+5** |
| 8-9 | **−1** | | 22-23 | **+6** |
| 10-11 | **0** | | 24-25 | **+7** |
| 12-13 | **+1** | | 30 | **+10** |

**เคล็ดลับจำง่าย:** เลข 10-11 = 0, ทุก ๆ **2 แต้ม** ที่เพิ่มขึ้น = **+1**

> **เพดานปกติ:** ค่า Ability Score สูงสุดคือ **20** (Modifier +5) ยกเว้นบาง Feat หรือของวิเศษที่ดันขึ้นไปได้ถึง **30**

## Skills — ทักษะ 18 อย่าง

Skill คือ "ความชำนาญเฉพาะทาง" ที่ผูกอยู่กับ Ability ตัวใดตัวหนึ่ง

### ตารางสกิลทั้งหมด

| Skill (อังกฤษ) | Ability | ใช้เมื่อไหร่ |
|---|---|---|
| **กีฬา/กายกรรมหนัก (Athletics)** | STR | ปีนป่าย ว่ายน้ำ กระโดด **Grapple/Shove** |
| **กายกรรม (Acrobatics)** | DEX | ทรงตัว ตีลังกา หลุดจากการถูกจับ |
| **มือไว (Sleight of Hand)** | DEX | ล้วงกระเป๋า ซ่อนของ เล่นกล |
| **การซ่อนตัว (Stealth)** | DEX | ย่องเงียบ ซ่อนตัว |
| **ความรู้เวทมนตร์ (Arcana)** | INT | จดจำสเปล รู้จักของวิเศษ สัญลักษณ์เวท |
| **ประวัติศาสตร์ (History)** | INT | เหตุการณ์ในอดีต อาณาจักรเก่า สงคราม |
| **การสืบสวน (Investigation)** | INT | หาเบาะแส วิเคราะห์ร่องรอย หากับดักที่ซ่อน |
| **ธรรมชาติวิทยา (Nature)** | INT | ความรู้เรื่องพืช สัตว์ ภูมิอากาศ |
| **ศาสนา (Religion)** | INT | เทพเจ้า พิธีกรรม ลัทธิ อันเดด |
| **การจัดการสัตว์ (Animal Handling)** | WIS | ทำให้สัตว์สงบ ควบคุมม้า อ่านใจสัตว์ |
| **การอ่านใจคน (Insight)** | WIS | รู้ว่าคนโกหก อ่านเจตนา |
| **การแพทย์ (Medicine)** | WIS | วินิจฉัยโรค ช่วยคนใกล้ตาย |
| **การรับรู้ (Perception)** | WIS | **สกิลที่ใช้บ่อยที่สุด** — สังเกตเห็น/ได้ยินสิ่งต่าง ๆ |
| **การเอาตัวรอด (Survival)** | WIS | ตามรอย หาอาหาร นำทาง ทำนายอากาศ |
| **การหลอกลวง (Deception)** | CHA | โกหก ปลอมตัว ตบตา |
| **การข่มขู่ (Intimidation)** | CHA | ขู่ให้กลัว บีบให้ทำตาม |
| **การแสดง (Performance)** | CHA | ร้องเพลง เต้น เล่นดนตรี เล่าเรื่อง |
| **การโน้มน้าว (Persuasion)** | CHA | ขอความช่วยเหลือ ต่อรอง สร้างมิตร |

### วิธีคำนวณค่าสกิล

```
Skill Modifier = Ability Modifier + Proficiency Bonus (ถ้ามี Proficiency ในสกิลนั้น)
```

> ตัวอย่าง: ตัวละครเลเวล 3 มี DEX 16 (+3) และมี Proficiency ใน Stealth (Prof +2)
> **Stealth = +5** ทอยว่า `1d20 + 5`
> แต่ Acrobatics (DEX เหมือนกันแต่ไม่มี Proficiency) **+3** เท่านั้น

### การรับรู้แบบเฉื่อย (Passive Perception)

DM ใช้เลขนี้ตัดสินว่าคุณ "เห็นของที่ซ่อนอยู่โดยไม่ต้องทอย" ไหม

```
Passive Perception = 10 + Perception Modifier
```
- มี **Advantage** **+5**
- มี **Disadvantage** **−5**

## Saving Throws — การทอยต้านทาน

ต่างจาก Ability Check ตรงที่ **Saving Throw คือการตอบสนองต่อภัยที่มาหาเรา** ไม่ใช่การกระทำที่เราตั้งใจทำ

| Save | ใช้ต้านอะไร |
|---|---|
| **STR Save** | ถูกผลัก ถูกดูดเข้าไป ต้านแรงกาย |
| **DEX Save** | หลบระเบิด กับดัก ลมหายใจมังกร (Fireball!) |
| **CON Save** | ทนพิษ ทนโรค **รักษา Concentration ตอนโดนตี** |
| **INT Save** | ต้านการโจมตีจิตใจ ภาพลวงตา |
| **WIS Save** | ต้านการควบคุมจิต ความกลัว การสะกดจิต |
| **CHA Save** | ต้านการถูกเนรเทศ ถูกครอบงำวิญญาณ |

**ทุกคลาสถนัด Saving Throw 2 อย่าง** (ได้ Proficiency Bonus บวกเพิ่ม) — ดูได้ในไฟล์คลาสของตัวเอง

> **Save ที่สำคัญที่สุดคือ DEX, CON, WIS** เพราะสเปลอันตรายส่วนใหญ่ใช้ 3 อย่างนี้

## วิธีกำหนดค่า Ability Score ตอนสร้างตัวละคร

เลือกวิธีใดวิธีหนึ่ง (**ถาม DM ก่อนว่าโต๊ะนี้ใช้วิธีไหน**)

### วิธีที่ 1: ชุดค่ามาตรฐาน (Standard Array) แนะนำมือใหม่

ใช้ชุดตัวเลขนี้เลย เอาไปใส่ 6 ช่องตามใจ:

```
15, 14, 13, 12, 10, 8
```

**ข้อดี:** เร็ว ยุติธรรม ทุกคนแรงเท่ากัน ไม่ต้องลุ้น

### วิธีที่ 2: ซื้อแต้ม (Point Buy)

มี **27 แต้ม** ให้ซื้อ ทุกค่าเริ่มที่ 8 (ซื้อได้สูงสุด 15 ก่อนบวกจาก Background)

| Score | แต้มที่ใช้ (สะสม) |
|---|---|
| 8 | 0 |
| 9 | 1 |
| 10 | 2 |
| 11 | 3 |
| 12 | 4 |
| 13 | 5 |
| 14 | **7** |
| 15 | **9** |

**ตัวอย่างการแบ่ง 27 แต้ม:**
- `15, 15, 15, 8, 8, 8` = 9+9+9 = **27** (สุดโต่ง)
- `15, 14, 13, 12, 10, 8` = 9+7+5+4+2+0 = **27** (เท่ากับ Standard Array พอดี)
- `14, 14, 14, 12, 10, 10` = 7+7+7+4+2+2 = **27** (สมดุล)

### วิธีที่ 3: ทอยเต๋า (Rolling)

ทอย **`4d6 ตัดลูกต่ำสุดทิ้ง`** ทำ 6 ครั้ง แล้วเอา 6 ค่านั้นไปจัดใส่ช่อง

> ทอยได้ `6, 4, 3, 1` ตัด `1` ทิ้ง `6+4+3 = 13`

**ข้อดี:** ลุ้นสนุก อาจได้ 18
**ข้อเสีย:** อาจได้ค่าห่วยมากแล้วต้องเล่นทั้งแคมเปญ (บางโต๊ะให้ทอยใหม่ถ้าผลรวมต่ำเกินไป)

## Background ให้ค่าพลังเพิ่ม (กฎใหม่ 2024!)

> **นี่คือความเปลี่ยนแปลงใหญ่ของกฎ 2024** — เมื่อก่อน Race (Species) เป็นตัวให้ค่าพลังเพิ่ม แต่ตอนนี้ **Species ไม่ให้ค่าพลังแล้ว** ทั้งหมดมาจาก **Background**

แต่ละ Background ระบุ **Ability Score 3 ตัว** ให้เลือกบวกแบบใดแบบหนึ่ง:

| แบบ | วิธีบวก |
|---|---|
| **แบบ A** | **+2** ให้ 1 ตัว และ **+1** ให้อีก 1 ตัว |
| **แบบ B** | **+1** ให้ทั้ง 3 ตัว |

> **ตัวอย่าง:** Background `Soldier` ระบุ STR, DEX, CON
> - แบบ A: STR **+2**, CON **+1**
> - แบบ B: STR **+1**, DEX **+1**, CON **+1**

**เพดานตอนเลเวล 1 คือ 17** (Standard Array 15 + 2 = 17)

---

## การเพิ่มค่าพลังตอนเลเวลสูงขึ้น

เมื่อถึงเลเวลที่ได้ **Ability Score Improvement / การเพิ่มค่าความสามารถ (ASI)** — โดยทั่วไปคือ **เลเวล 4, 8, 12, 16, 19** (Fighter และ Rogue ได้เพิ่มอีก) คุณเลือกได้ 1 อย่าง:

1. เอา **Ability Score Improvement Feat** — เพิ่มค่าพลัง **+2 ให้ 1 ตัว** หรือ **+1 ให้ 2 ตัว** (สูงสุดไม่เกิน 20)
2. เอา **General Feat** อื่นแทน — ดู [General Feats](../05-feats/general-feats.md)

> **คำแนะนำมือใหม่:** เลเวล 4 ครั้งแรก ควรดันค่าหลักของคลาสให้ถึง **18 หรือ 20** ก่อน แล้วค่อยเก็บ Feat สนุก ๆ ทีหลัง

## ค่าพลังหลักของแต่ละคลาส (Primary Ability)

ค่านี้ควรเป็นค่าที่สูงที่สุดของคุณ เพราะใช้ทั้งโจมตีและร่ายเวท

| คลาส | ค่าหลัก | ค่ารอง (แนะนำ) |
|---|---|---|
| **Barbarian** | STR | CON |
| **Bard** | CHA | DEX, CON |
| **Cleric** | WIS | CON, STR/DEX |
| **Druid** | WIS | CON, DEX |
| **Fighter** | STR **หรือ** DEX | CON |
| **Monk** | DEX **และ** WIS | CON |
| **Paladin** | STR **และ** CHA | CON |
| **Ranger** | DEX **และ** WIS | CON |
| **Rogue** | DEX | CON, INT/CHA |
| **Sorcerer** | CHA | CON, DEX |
| **Warlock** | CHA | CON, DEX |
| **Wizard** | INT | CON, DEX |

> **CON สำคัญกับทุกคลาส** เพราะเพิ่ม HP ทุกเลเวล และใช้ทอยรักษา Concentration
