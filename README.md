# คู่มือ Dungeons & Dragons (D&D) ฉบับผู้เล่นใหม่

คู่มือภาษาไทยสำหรับคนที่อยากเริ่มเล่น **ดันเจียนส์ แอนด์ ดราก้อนส์ (Dungeons & Dragons)** โดยอ้างอิงกฎล่าสุดคือ **คู่มือผู้เล่น ฉบับปี 2024 (D&D 2024 Player's Handbook)** หรือที่หลายคนเรียกว่า "D&D 5e ฉบับปรับปรุง 2024" / "One D&D"

> **หมายเหตุเรื่องภาษา:** เอกสารชุดนี้เขียนเป็นภาษาไทย และใช้รูปแบบ **คำไทยก่อน แล้ววงเล็บภาษาอังกฤษต่อท้าย** เช่น **โหมดคลั่ง (Rage)**, **การโจมตีลับ (Sneak Attack)**
> เพราะโต๊ะเล่นส่วนใหญ่และหนังสือจริงใช้คำอังกฤษ จึงคงคำอังกฤษไว้ให้เทียบได้เสมอ ส่วนคำที่ผู้เล่นไทยเรียกทับศัพท์อยู่แล้ว (HP, AC, Spell Slot, Saving Throw) คงไว้เป็นอังกฤษล้วน

## ความแตกต่างสำคัญของกฎ 2024 กับกฎเก่า (2014)

ถ้าเคยดูคลิปหรืออ่านคู่มือเก่ามาก่อน ต้องรู้ว่าอะไรเปลี่ยนบ้าง:

| หัวข้อ | กฎเก่า 2014 | **กฎใหม่ 2024** |
|---|---|---|
| คำเรียกเผ่าพันธุ์ | Race | **Species** |
| ค่าพลังบวกเพิ่ม | ได้จาก Race | **ได้จาก Background แทน** |
| Background | ให้แค่สกิลกับของ | **ให้ค่าพลัง + Origin Feat ด้วย** |
| Subclass (สายย่อย) | เลือกที่เลเวลต่างกันแต่ละคลาส | **ทุกคลาสเลือกที่เลเวล 3** |
| อาวุธ | ไม่มีลูกเล่นพิเศษ | **มี Weapon Mastery (ความชำนาญอาวุธ)** |
| Inspiration | Inspiration | **ทอยใหม่ได้เลย (Heroic Inspiration)** |
| Exhaustion | 6 ระดับ ผลต่างกัน | **6 ระดับ ผลเหมือนกันหมด (-2 ทุกการทอย d20, -5 ความเร็ว)** |
| Surprise (จู่โจม) | มีรอบจู่โจมพิเศษ | **ไม่มีรอบพิเศษ แต่ทอย Initiative แบบ Disadvantage** |
| Unarmed Strike | ต่อยได้อย่างเดียว | **ต่อย / Grapple (จับล็อก) / Shove (ผลัก)** |

## คำศัพท์ที่เจอบ่อยที่สุด (Quick Glossary)

| คำอังกฤษ | ความหมายสั้น ๆ |
|---|---|
| **ผู้คุมเกม (DM — Dungeon Master)** | คนเล่าเรื่อง คุมมอนสเตอร์ ตัดสินกฎ |
| **ตัวละครผู้เล่น (PC — Player Character)** | ตัวละครที่เราเล่น |
| **ตัวละครฝ่าย DM (NPC — Non-Player Character)** | ตัวประกอบทั้งหมดในโลก |
| **พลังชีวิต (HP — Hit Points)** | เลือดของเรา หมดแล้วสลบ |
| **ค่าป้องกัน (AC — Armor Class)** | เลขที่ศัตรูต้องทอยให้ถึงจึงจะโดนเรา |
| **ค่าความยาก (DC — Difficulty Class)** | เลขที่เราต้องทอยให้ถึงจึงจะสำเร็จ |
| **การทอยทดสอบความสามารถ (Ability Check)** | ทอย d20 + modifier |
| **การทอยต้านทาน (Saving Throw)** | ทอยเพื่อหลบ/ต้านผลร้าย |
| **โบนัสความชำนาญ (Proficiency Bonus)** | เลขที่บวกเพิ่มในสิ่งที่เราถนัด (+2 ถึง +6) |
| **การพักยาว (Long Rest)** | นอน 8 ชม. ฟื้นเกือบทุกอย่าง |
| **การพักสั้น (Short Rest)** | พัก 1 ชม. ฟื้นบางอย่าง |
| **รอบการเล่น (Session)** | การนัดเล่น 1 ครั้ง |
| **แคมเปญ (Campaign)** | เนื้อเรื่องยาวที่เล่นต่อกันหลายเซสชัน |
| **วันช็อต (One-shot)** | เนื้อเรื่องสั้นจบในเซสชันเดียว |
