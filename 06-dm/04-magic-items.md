# ของวิเศษและสมบัติ (Magic Items & Treasure)

[กลับหน้ารวม DM](00-dm-overview.md) | [สารบัญ](../README.md)

---

## ระดับความหายาก (Rarity)

| ระดับ | ชื่อไทย | เลเวลที่เหมาะ | ราคาโดยประมาณ |
|---|---|---|---|
| **Common** | ทั่วไป | 1+ | 100 GP |
| **Uncommon** | ไม่ธรรมดา | 1-4 | 400 GP |
| **Rare** | หายาก | 5-10 | 4,000 GP |
| **Very Rare** | หายากมาก | 11-16 | 40,000 GP |
| **Legendary** | ระดับตำนาน | 17-20 | 200,000 GP |
| **Artifact** | วัตถุโบราณ | ตามเนื้อเรื่อง | ประเมินค่าไม่ได้ |

> **ราคาเป็นแค่ตัวเลขอ้างอิงสำหรับ DM** — ในโลก D&D ส่วนใหญ่ ของวิเศษ **ซื้อขายไม่ได้ตามร้านทั่วไป**
> ถ้าโต๊ะคุณอยากให้ซื้อขายได้ ให้บอกในเซสชันศูนย์ (Session Zero)

---

## การผูกพัน (Attunement)

ของวิเศษบางชิ้นระบุว่า **"ต้องมี Attunement"** หมายความว่า:

| กฎ | รายละเอียด |
|---|---|
| **วิธีทำ** | ใช้เวลา **Short Rest 1 ครั้ง** จดจ่อกับของชิ้นนั้น |
| **จำนวนสูงสุด** | **3 ชิ้นต่อคน** (Thief Rogue เลเวล 13 ได้ 4 ชิ้น) |
| **ยกเลิก** | ใช้เวลา Short Rest อีกครั้ง หรือทิ้งของไปเกิน 24 ชั่วโมง |
| **ข้อจำกัด** | บางชิ้นต้องเป็นคลาสหรือเผ่าพันธุ์ที่ระบุเท่านั้น |

> **Attunement คือเบรกที่สำคัญที่สุดในการควบคุมพลังผู้เล่น** — ต่อให้เจอของแรง 10 ชิ้น ก็ใช้ได้แค่ 3

## แจกของวิเศษเมื่อไหร่และเท่าไหร่

### แนวทางตามระดับ (Tier)

| ระดับเลเวล | ควรมีของวิเศษถาวรกี่ชิ้นต่อคน | ระดับความหายากที่พบ |
|---|---|---|
| **1-4** | 0-1 ชิ้น | Common, Uncommon |
| **5-10** | 2-3 ชิ้น | Uncommon, Rare |
| **11-16** | 3-4 ชิ้น | Rare, Very Rare |
| **17-20** | 4-6 ชิ้น | Very Rare, Legendary |

> **D&D ออกแบบมาให้เล่นได้โดยไม่มีของวิเศษเลย** — ของวิเศษคือ "ของหวาน" ไม่ใช่ "อาหารหลัก"
> ถ้าไม่แน่ใจ ให้แจกน้อยไว้ก่อน เพิ่มทีหลังง่ายกว่าเอาคืน

### หลักการแจกที่ดี

| หลักการ | เหตุผล |
|---|---|
| **ให้ตรงกับตัวละคร** | ให้ธนู +1 กับ Ranger ไม่ใช่กับ Wizard |
| **ให้ของที่เปิดทางเล่นใหม่** | ของที่ให้ความสามารถใหม่สนุกกว่าของที่ +1 เฉย ๆ |
| **ใส่เรื่องราวให้ของ** | "ดาบของนายพลที่หายไป" น่าจดจำกว่า "Longsword +1" |
| **ให้ตอนจบเนื้อเรื่องสำคัญ** | ทำให้รู้สึกว่าได้มาเพราะความสำเร็จ |
| **กระจายให้ทุกคน** | อย่าให้คนเดียวได้ 3 ชิ้นในขณะที่คนอื่นไม่ได้เลย |

|---|---|

| **Wish (ทุกรูปแบบ)** | ผู้เล่นจะขอสิ่งที่ทำลายสมดุลเกม ต้องคุยกฎกันก่อน |

| **ของที่ให้บินตั้งแต่เลเวลต่ำ** | ทำให้การเผชิญหน้าที่ออกแบบไว้ไร้ความหมาย |

## ระบบสมบัติ (Treasure)

### แบ่งเป็น 2 แบบ

| แบบ | เมื่อไหร่ | มีอะไร |
|---|---|---|
| **สมบัติติดตัว (Individual Treasure)** | จากศัตรูแต่ละตัว | เหรียญเล็กน้อย ของใช้ |
| **กองสมบัติ (Treasure Hoard)** | ในรังบอส ห้องสมบัติ | เหรียญเยอะ + อัญมณี + ของศิลปะ + ของวิเศษ |

### ปริมาณเหรียญโดยประมาณต่อกองสมบัติ

| ระดับเลเวล | เหรียญโดยประมาณต่อกอง | ของวิเศษ |
|---|---|---|
| **1-4** | 100-1,000 GP | 0-2 ชิ้น (Common / Uncommon) |
| **5-10** | 1,000-10,000 GP | 1-3 ชิ้น (Uncommon / Rare) |
| **11-16** | 10,000-50,000 GP | 2-4 ชิ้น (Rare / Very Rare) |
| **17-20** | 50,000+ GP | 3-6 ชิ้น (Very Rare / Legendary) |

> **ผู้เล่นจะไม่รู้สึกว่าได้เยอะถ้าให้แต่เหรียญ** — ให้ **อัญมณีและของศิลปะ** ปนไปด้วย เพราะบรรยายได้สนุกกว่า
> "ถ้วยทองประดับทับทิม มูลค่า 250 GP" น่าจดจำกว่า "250 GP"

### สมบัติที่ไม่ใช่เงินและของวิเศษ

**รางวัลที่ดีที่สุดมักไม่ใช่ของ** — พิจารณาให้สิ่งเหล่านี้แทน

| รางวัล | ตัวอย่าง |
|---|---|
| **ข้อมูล** | แผนที่ไปสุสานโบราณ, ชื่อจริงของปีศาจ |
| **บุญคุณ** | ขุนนางติดหนี้ชีวิตผู้เล่น |
| **ตำแหน่งและที่ดิน** | ได้รับแต่งตั้งเป็นอัศวิน, ได้ปราสาทร้าง |
| **สิทธิพิเศษ** | เข้าห้องสมุดต้องห้ามได้, ได้ส่วนลดถาวรจากกิลด์ |
| **พันธมิตร** | NPC ที่จะมาช่วยตอนศึกใหญ่ |

## ระบบป้อมปราการ (Bastion) — กฎเสริมใหม่ 2024

**กฎ 2024 เพิ่มระบบให้ตัวละครมี "ฐานที่มั่น" ของตัวเองตั้งแต่เลเวล 5**

| หัวข้อ | รายละเอียด |
|---|---|
| **เริ่มได้เมื่อ** | เลเวล 5 |
| **คืออะไร** | ที่พัก ป้อม หอคอย หรือวิหารที่ตัวละครเป็นเจ้าของ |
| **มีอะไร** | **ห้องพิเศษ (Special Facilities)** ที่ให้ประโยชน์ต่างกัน เช่น ห้องทดลอง คลังอาวุธ ห้องสมุด สวนสมุนไพร |
| **ทำงานเมื่อไหร่** | ทุกครั้งที่ผ่านไป 7 วันในเกม ให้ทอย **Bastion Turn** เพื่อดูว่าเกิดอะไรขึ้น |
| **ได้อะไร** | ผลิตของ หาข้อมูล หาเงิน ฝึกลูกน้อง หรือเจอเหตุการณ์สุ่ม |

> **เหมาะกับแคมเปญที่มีช่วงเวลาว่างระหว่างการผจญภัย** — ถ้าโต๊ะคุณเล่นแบบผจญภัยต่อเนื่องไม่หยุด ระบบนี้อาจไม่จำเป็น

## รายการตรวจก่อนแจกของวิเศษ

```
[ ] ของชิ้นนี้มีคนในกลุ่มที่ใช้ได้จริงไหม
[ ] ถ้าใช้แล้วจะทำให้การเผชิญหน้าที่เตรียมไว้พังไหม (เช่น บินได้ตั้งแต่เลเวล 3)
[ ] ต้อง Attunement ไหม และคนนั้นมีช่องว่างเหลือไหม
[ ] มีเรื่องราวหรือที่มาไหม หรือเป็นแค่ของที่โผล่มาเฉย ๆ
[ ] ผู้เล่นคนอื่นได้อะไรบ้างในรอบนี้
[ ] ถ้าอยากเอาคืนทีหลัง มีเหตุผลในเนื้อเรื่องไหม (ปกติไม่ควรเอาคืน)
```

## สรุปเรื่องของวิเศษในหนึ่งบรรทัด

> **แจกน้อยไว้ก่อน ให้ตรงกับตัวละคร ใส่เรื่องราวให้ทุกชิ้น และใช้ Attunement 3 ช่องเป็นเบรกควบคุมพลัง — ของวิเศษคือของหวาน ไม่ใช่อาหารหลัก**
