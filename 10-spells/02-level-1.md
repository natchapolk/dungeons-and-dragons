### โล่ (Shield)
**สเปลระดับ 1 · Abjuration**

| | |
|---|---|
| **Casting Time** | **Reaction** — เมื่อคุณถูกโจมตี หรือถูก `Magic Missile` เล็ง |
| **Range** | Self |
| **Components** | V, S |
| **Duration** | จนถึงเริ่มเทิร์นหน้าของคุณ |
| **คลาส** | Sorcerer, Wizard |

**+5 AC ทันที** รวมถึงกับการโจมตีที่กระตุ้นสเปลนี้
**ภูมิคุ้มกัน `Magic Missile` โดยสมบูรณ์**

> **[แนะนำ]** **สเปลที่ดีที่สุดของสายเวท** — ใช้ได้หลังจากศัตรูทอยแล้ว แต่ก่อน DM บอกว่าโดน
> ทำให้การโจมตีที่จะโดน กลายเป็นพลาดได้

### เกราะเวท (Mage Armor)
**สเปลระดับ 1 · Abjuration**

| | |
|---|---|
| **Casting Time** | Action |
| **Range** | สัมผัส |
| **Components** | V, S, M (หนังฟอกชิ้นเล็ก) |
| **Duration** | **8 ชั่วโมง** |
| **คลาส** | Sorcerer, Wizard |

เป้าหมายที่ **ไม่ใส่เกราะ** ได้ **AC = 13 + Dexterity modifier**
สเปลจบถ้าเป้าหมายใส่เกราะ หรือคุณยกเลิก (Action)

> **[แนะนำ]** **ร่ายทุกเช้าก่อนออกเดินทาง** — 8 ชั่วโมงครอบคลุมทั้งวัน
