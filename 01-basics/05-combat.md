# การต่อสู้ (Combat)

[กลับสารบัญ](../README.md)

---

## โครงสร้างเวลาในการต่อสู้

| หน่วย | เท่ากับ |
|---|---|
| **รอบ (Round)** | **6 วินาที** ในโลกของเกม — ทุกคนได้เล่น 1 ครั้ง |
| **เทิร์น/ตา (Turn)** | ตาของคนคนเดียวภายใน 1 Round |

---

## ลำดับการต่อสู้ทีละขั้น

```
1. DM ประกาศว่าเริ่มการต่อสู้
2. ทุกคนทอย Initiative (1d20 + DEX modifier)
3. เรียงลำดับจากมากไปน้อย
4. เล่นตามลำดับจนครบ = จบ 1 Round
5. วนซ้ำจนกว่าฝ่ายใดฝ่ายหนึ่งจะแพ้/หนี/ยอมแพ้
```

### ลำดับการเล่น (Initiative)

```
Initiative = 1d20 + DEX modifier
```

- ทอย **ครั้งเดียวตอนเริ่มการต่อสู้** ใช้ลำดับนั้นไปตลอด
- **เสมอกัน?** ผู้เล่นตกลงกันเอง / DM ตัดสิน (บางโต๊ะให้คนที่ DEX สูงกว่าไปก่อน)

### การจู่โจม (Surprise) — กฎใหม่ 2024

> **กฎ 2024 ไม่มี "Surprise Round" (รอบจู่โจมพิเศษ) แล้ว**

ถ้าฝ่ายหนึ่งจู่โจมอีกฝ่ายได้สำเร็จ (เช่นซุ่มโจมตี):
**ฝ่ายที่ถูกจู่โจมทอย Initiative แบบ Disadvantage** เท่านั้น — ไม่ได้เสียเทิร์นทั้งเทิร์นเหมือนกฎเก่า

---

## ในเทิร์นของคุณทำอะไรได้บ้าง

ทุกเทิร์นคุณได้ทั้งหมดนี้ (ใช้หรือไม่ใช้ก็ได้):

| ทรัพยากร | จำนวน | หมายเหตุ |
|---|---|---|
| **การเคลื่อนที่ (Movement)** | เท่ากับ **ปกติ 30 ฟุต (Speed)** | แบ่งย่อยได้ เดินก่อน–ตี–เดินต่อ |
| **แอ็กชัน (Action)** | **1 ครั้ง** | อย่างหลัก เช่น โจมตี ร่ายเวท |
| **โบนัสแอ็กชัน (Bonus Action)** | **1 ครั้ง** | ใช้ได้เฉพาะเมื่อมี Feature ที่ระบุว่าใช้ |
| **รีแอ็กชัน (Reaction)** | **1 ครั้ง ต่อ Round** | ใช้ได้แม้ไม่ใช่เทิร์นเรา |
| **การโต้ตอบฟรี (Free Interaction)** | **1 ครั้ง** | เปิดประตู ชักอาวุธ ดื่มของ ฯลฯ |

> **จุดที่มือใหม่เข้าใจผิดบ่อย: Bonus Action ไม่ใช่ "แอ็กชันเพิ่ม"**
> คุณใช้ Bonus Action ได้ **เฉพาะเมื่อมีความสามารถบอกไว้ชัดว่า "ใช้เป็น Bonus Action"** เท่านั้น ไม่ใช่ว่าจะโจมตีเพิ่มได้ฟรี ๆ

---

## Actions มาตรฐาน (ใช้ได้ทุกคน ทุกคลาส)

| Action | ทำอะไร |
|---|---|
| **โจมตี (Attack)** | โจมตี 1 ครั้ง (หรือมากกว่าถ้ามี Extra Attack) |
| **วิ่ง (Dash)** | **เพิ่มระยะเคลื่อนที่อีกเท่าตัว** ในเทิร์นนี้ |
| **ถอนตัว (Disengage)** | เคลื่อนที่ออกจากศัตรูโดย **ไม่โดน Opportunity Attack** |
| **หลบ (Dodge)** | จนถึงเทิร์นหน้า: ศัตรูโจมตีเราแบบ **Disadvantage** และเราทอย **DEX Save แบบ Advantage** |
| **ช่วยเหลือ (Help)** | ให้เพื่อนได้ **Advantage** ในการทอย 1 ครั้ง หรือช่วยโจมตีศัตรูที่อยู่ในระยะ 5 ฟุตจากเรา |
| **ซ่อนตัว (Hide)** | ทอย **DEX (Stealth) DC 15** เพื่อได้สภาวะ **Invisible** |
| **โน้มน้าว (Influence)** | พยายามเปลี่ยนทัศนคติสัตว์/คน (Persuasion, Deception, Intimidation, Performance, Animal Handling) |
| **ใช้เวท (Magic)** | ร่ายสเปล หรือใช้ของวิเศษ |
| **เตรียมพร้อม (Ready)** | ตั้งเงื่อนไข "ถ้า X เกิด ฉันจะทำ Y" — ใช้ **Reaction** เมื่อเงื่อนไขเกิด |
| **ค้นหา (Search)** | ค้นหาสิ่งที่ซ่อนอยู่ (Perception, Investigation, Insight, Medicine, Survival) |
| **ศึกษา (Study)** | ใช้ INT ระลึกความรู้ (Arcana, History, Investigation, Nature, Religion) |
| **ใช้งานสิ่งของ (Utilize)** | ใช้ของที่ไม่ใช่อาวุธ เช่นดึงคันโยก จุดคบไฟ |

> **Dodge เป็น Action ที่มือใหม่มองข้ามที่สุด** — ถ้า HP เหลือน้อยและไม่มีอะไรทำที่คุ้มค่า Dodge ช่วยชีวิตได้จริง

## Bonus Actions ที่พบบ่อย

| ที่มา | ทำอะไร |
|---|---|
| **Two-Weapon Fighting** | ถือ **อาวุธ Light** 2 มือ — หลังใช้ Attack action โจมตีด้วยมืออีกข้าง (ไม่บวก Ability modifier ในดาเมจ เว้นแต่มี Fighting Style: Two-Weapon Fighting) |
| **Rage** (Barbarian) | เข้าสู่โหมดคลั่ง |
| **Second Wind** (Fighter) | ฟื้น HP |
| **Cunning Action** (Rogue) | Dash / Disengage / Hide |
| **สเปล (Healing Word)** | รักษาระยะไกล |
| **Bardic Inspiration** (Bard) | ให้เต๋าโบนัสเพื่อน |
| **Flurry of Blows** (Monk) | โจมตีมือเปล่าเพิ่ม |
| **Spiritual Weapon** (Cleric) | ขยับ+โจมตีด้วยอาวุธวิญญาณ |

## Reactions ที่พบบ่อย

| Reaction | เกิดเมื่อ |
|---|---|
| **Opportunity Attack** | ศัตรูที่อยู่ประชิด (5 ฟุต) **เคลื่อนออกจากระยะเรา** ด้วยการเดิน |
| **สเปล (Shield)** | ถูกโจมตี +5 AC ทันที |
| **สเปล (Counterspell)** | ศัตรูร่ายเวท ขัดขวาง |
| **Ready Action** | เงื่อนไขที่ตั้งไว้เกิดขึ้น |
| **สเปล (Absorb Elements)** | โดนดาเมจธาตุ |

### การโจมตีฉวยโอกาส (Opportunity Attack) — กฎละเอียด

**เกิดเมื่อ:** ศัตรูที่มองเห็นได้ **เดินออกจากระยะ 5 ฟุตของเรา**

**ทำได้:** โจมตีระยะประชิด **1 ครั้ง** (ใช้ Reaction)

**ไม่เกิดเมื่อ:**
- ศัตรูใช้ **Disengage**
- ศัตรูถูก **Teleport** หรือถูกผลัก/ดึงโดยไม่ได้ใช้ Movement ของตัวเอง
- ศัตรูขยับเข้าหาเรา หรือขยับรอบ ๆ เราโดยไม่ออกนอกระยะ 5 ฟุต

## การโจมตี (Making an Attack)

```
ขั้นที่ 1: เลือกเป้าหมาย (ต้องอยู่ในระยะ)
ขั้นที่ 2: ทอย Attack Roll
ขั้นที่ 3: ถ้าโดน ทอย Damage
```

### การทอยโจมตี (Attack Roll)

```
1d20 + Ability Modifier + Proficiency Bonus (ถ้าถนัดอาวุธนั้น)
```

เทียบกับ **AC (Armor Class)** ของเป้าหมาย — **ได้เท่ากับหรือมากกว่า = โดน**

| ประเภทการโจมตี | ใช้ Ability |
|---|---|
| อาวุธระยะประชิด (Melee) | **STR** |
| อาวุธระยะไกล (Ranged) | **DEX** |
| อาวุธที่มีคุณสมบัติ **Finesse** | **เลือก STR หรือ DEX** ก็ได้ |
| อาวุธ **Thrown** ที่เป็นอาวุธประชิด | ใช้ Ability เดียวกับตอนตีประชิด |
| สเปล | **ค่าร่ายเวทของคลาส** (INT/WIS/CHA) |

### การทอยดาเมจ (Damage Roll)

```
เต๋าของอาวุธ + Ability Modifier (ตัวเดียวกับที่ใช้โจมตี)
```

> **ไม่บวก Proficiency Bonus ในดาเมจ**

**Critical Hit (ทอยได้ 20):** ทอย **เต๋าดาเมจสองเท่า** ตัวบวกเท่าเดิม

## Hit Points, การตาย และการฟื้น

### เมื่อ HP เหลือ 0

| สถานการณ์ | ผล |
|---|---|
| HP เหลือ 0 | **หมดสติ (Unconscious)** และเริ่มทอย **Death Saving Throw** |
| ดาเมจเกินมาเท่ากับ **HP สูงสุด** ของเรา | **ตายทันที (Instant Death)** |

### การทอยเอาชีวิตรอด (Death Saving Throws)

ทุกเทิร์นที่หมดสติ ให้ทอย **d20 เปล่า ๆ** (ไม่บวกอะไรเลย)

| ผลทอย | ผลลัพธ์ |
|---|---|
| **10 ขึ้นไป** | **สำเร็จ 1 ครั้ง** |
| **9 หรือน้อยกว่า** | **ล้มเหลว 1 ครั้ง** |
| **Natural 1** | **ล้มเหลว 2 ครั้ง** |
| **Natural 20** | **ฟื้นทันทีด้วย HP 1** |

- **สำเร็จ 3 ครั้ง** **อาการคงที่ (Stable)** ไม่ต้องทอยต่อ แต่ยังหมดสติจนกว่าจะได้รับการรักษาหรือผ่านไป 1d4 ชั่วโมง
- **ล้มเหลว 3 ครั้ง** **ตาย**

> **ถูกโจมตีระยะประชิดตอนหมดสติ = ล้มเหลวอัตโนมัติ 2 ครั้ง (Critical Hit)** ดังนั้นควรรีบรักษาเพื่อน!

### วิธีช่วยเพื่อนที่หมดสติ

| วิธี | ผล |
|---|---|
| **สเปลรักษา** (เช่น Healing Word, Cure Wounds) | ฟื้นด้วย HP ตามที่รักษา และตัวนับ Death Save รีเซ็ต |
| **ยาฟื้นพลัง (Healing Potion)** | ต้องมีคนกรอกให้ (**ใช้ Action**) |
| **ใช้ Action (Medicine Check DC 10)** | ทำให้ **Stable** แต่ยังหมดสติที่ 0 HP |
| **Spare the Dying** (Cantrip) | ทำให้ **Stable** ทันที |

### HP ชั่วคราว (Temporary Hit Points)

- เป็น **โล่ HP แยก** — ดาเมจจะลด Temp HP ก่อน แล้วค่อยลด HP จริง
- **ไม่สะสมกัน** — ถ้าได้อันใหม่ ต้องเลือกว่าจะเก็บอันไหน (เอาที่มากกว่า)
- **การรักษา (Healing) ไม่ฟื้น Temp HP**
- หายไปเมื่อ **Long Rest**

## การเคลื่อนที่และภูมิประเทศ

| กรณี | กฎ |
|---|---|
| **ภูมิประเทศยาก (Difficult Terrain)** | เดิน 1 ฟุต ใช้ระยะ **2 ฟุต** — เช่น หิมะ พงหนาม เศษซาก |
| **ปีน/ว่ายน้ำ (Climbing / Swimming)** | ใช้ระยะ **2 เท่า** เหมือน Difficult Terrain |
| **คลาน (Crawling)** | ใช้ระยะ **2 เท่า** |
| **ลุกจากท่านอน (Standing Up)** | ใช้ระยะ **ครึ่งหนึ่งของ Speed** |
| **กระโดดไกล (Long Jump)** | วิ่ง 10 ฟุตก่อน กระโดดได้ **เท่ากับค่า STR (เป็นฟุต)** |
| **กระโดดสูง (High Jump)** | วิ่ง 10 ฟุตก่อน กระโดดสูง **3 + STR modifier ฟุต** |
| **เดินผ่านตัวเพื่อน** | ได้ (นับเป็น Difficult Terrain) |
| **เดินผ่านตัวศัตรู** | ไม่ได้ ถ้าศัตรูตัวใหญ่กว่าเรา 1 ขนาดขึ้นไปจึงจะผ่านได้ |
| **หยุดในช่องเดียวกับคนอื่น** | ไม่ได้ (ยกเว้นเป้าหมาย Prone/หมดสติ) |

## ที่กำบัง (Cover)

| ระดับ | ผล |
|---|---|
| **กำบังครึ่งตัว (Half Cover)** | **+2 AC และ +2 DEX Save** |
| **กำบังสามในสี่ (Three-Quarters Cover)** | **+5 AC และ +5 DEX Save** |
| **กำบังเต็มตัว (Total Cover)** | **โจมตีตรง ๆ ไม่ได้เลย** |

## การโจมตีมือเปล่า (Unarmed Strike) — กฎใหม่ 2024

กฎ 2024 ทำให้การโจมตีมือเปล่ามีทางเลือก **3 แบบ** เลือกอย่างใดอย่างหนึ่งต่อการโจมตี 1 ครั้ง:

| ตัวเลือก | ผล |
|---|---|
| **ทำดาเมจ (Damage)** | ทอย Attack Roll ถ้าโดน ทำ **1 + STR modifier** Bludgeoning damage |
| **จับล็อก (Grapple)** | เป้าหมายทอย **STR Save หรือ DEX Save** (เลือกเอง) DC = **8 + STR mod + Prof** ถ้าล้มเหลว ติดสภาวะ **Grappled** |
| **ผลัก (Shove)** | เป้าหมายทอย Save เหมือนกัน ถ้าล้มเหลว **ผลักไป 5 ฟุต** หรือทำให้ **ล้มลง (Prone)** |

> **Grapple และ Shove ไม่ต้องทอย Attack Roll แล้ว** — เป็นการให้เป้าหมายทอย Save แทน (เปลี่ยนจากกฎ 2014)
> เป้าหมายต้องมีขนาดใหญ่กว่าเราไม่เกิน 1 ขนาด

## ความชำนาญอาวุธ (Weapon Mastery) — ระบบใหม่ 2024

**คลาสสายรบ** (Barbarian, Fighter, Monk, Paladin, Ranger, Rogue) ได้ความสามารถนี้ตั้งแต่เลเวล 1

- อาวุธแต่ละชนิดมี **คุณสมบัติชำนาญ (Mastery Property)** ติดมา
- คุณเลือกอาวุธได้จำนวนหนึ่ง (2-3 ชนิด ตามคลาส) แล้วจะปลดล็อกคุณสมบัตินั้น
- **เปลี่ยนตัวเลือกได้ตอน Long Rest**

 ดูรายละเอียดคุณสมบัติทั้ง 8 แบบใน [อุปกรณ์และอาวุธ](08-equipment.md)

## ประเภทดาเมจ (Damage Types) 13 แบบ

| ประเภท | ตัวอย่าง |
|---|---|
| **ทุบ/กระแทก (Bludgeoning)** | ค้อน กระบอง หินถล่ม ตกจากที่สูง |
| **แทง (Piercing)** | ลูกธนู หอก เขี้ยว |
| **ฟัน (Slashing)** | ดาบ ขวาน กรงเล็บ |
| **กรด (Acid)** | เลือดกรด สไลม์ |
| **เย็น (Cold)** | น้ำแข็ง Cone of Cold |
| **ไฟ (Fire)** | Fireball ลาวา |
| **พลังบริสุทธิ์ (Force)** | Magic Missile — **ต้านทานได้ยากที่สุด** |
| **สายฟ้า (Lightning)** | Lightning Bolt |
| **เน่าสลาย (Necrotic)** | อันเดด สเปลสายมืด |
| **พิษ (Poison)** | ยาพิษ ลมหายใจมังกรเขียว |
| **จิต (Psychic)** | การโจมตีทางจิตใจ |
| **แสงศักดิ์สิทธิ์ (Radiant)** | สเปลของ Cleric/Paladin |
| **เสียงกัมปนาท (Thunder)** | Thunderwave |

### Resistance / Vulnerability / Immunity

| คำ | ผล |
|---|---|
| **ต้านทาน (Resistance)** | รับดาเมจ **ครึ่งเดียว** (ปัดลง) |
| **อ่อนแอต่อ (Vulnerability)** | รับดาเมจ **สองเท่า** |
| **ภูมิคุ้มกัน (Immunity)** | รับดาเมจ **0** |

> **Resistance ไม่ทบซ้อน** — มี Resistance 2 อย่างต่อธาตุเดียวกัน ก็ยังลดครึ่งเดียว
> **ลำดับการคำนวณ:** บวก/ลบทั้งหมดก่อน คูณ Vulnerability หาร Resistance

## ตัวช่วยจำ: ในเทิร์นฉันทำอะไรได้บ้าง?

```
เทิร์นของฉัน ทำอะไรได้บ้าง

  Movement ______ ฟุต (แบ่งใช้ได้)
  Action เลือก 1 อย่าง จาก
                  Attack, Dash, Dodge, Disengage, Help, Hide,
                  Magic, Ready, Search, Study, Influence, Utilize
  Bonus Action ใช้ได้เฉพาะเมื่อมี Feature ที่ระบุไว้
  Free Action เปิดประตู ชักอาวุธ ฯลฯ 1 ครั้ง
  พูด พูดสั้น ๆ ได้ฟรี

  Reaction 1 ครั้งต่อรอบ ใช้นอกเทิร์นตัวเองได้
```
